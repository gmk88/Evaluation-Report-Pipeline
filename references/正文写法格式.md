# 正文写法格式

报告不直接在 Word 里排，而是写成几份纯文字文件（Markdown），由程序统一排成 Word／PDF。好处：版式全自动、计数自动算、目录页码自动回填、生成前自动查错。

## 一、项目文件夹里有什么

| 文件／文件夹 | 放什么 |
|---|---|
| 项目信息.md | 封面、声明、人员表、页眉页脚、附件清单用到的信息 |
| 检查规则.md | 本项目专用的检查（禁用说法、必须出现的表述等），可以空着 |
| 正文/ | 正文，一章一个文件：01_总论.md … 11_结论与建议.md（按文件名顺序拼接） |
| 图/ | 正文用到的图片 |
| 资料/ | 收到的原始资料（程序不读，只是归档） |
| 输出/ | 生成的 Word、PDF 和 校验报告.md（每次生成会覆盖） |

## 二、项目信息.md

```
- 项目名称：中国石化销售股份有限公司山西晋城阳城马沟加气站
- 封面名称：中国石化销售股份有限公司        ← 封面上一行一条，可写多条
- 封面名称：山西晋城阳城马沟加气站
- 报告编号：AT-2026-Y013
- 报告日期：2026年8月3日
- 建设单位：……
- 评价单位：……                              ← 同时用在声明、页脚
- 法定代表人：……

## 评价人员
| 类别 | 姓名 | 职称 | 专业 | 证书号 |
|---|---|---|---|---|
| 项目负责人 | …… | …… | …… | …… |      ← 同一类别连续写，人员表自动合并“人员类别”格

## 附件
1. 职业病危害预评价委托书                  ← 顺序就是附件编号
2. 项目备案文件（文件：资料/备案证.pdf）      ← 可注明文件位置，便于合订
```

还没定的写【待填】，生成时会列进待办。

可选一项 `- 表注：表后`：表注照旧排成表格后面的段落。不写这一项时，表注排进表格最后一行（见第四节）。`import` 导入旧稿时会自动写上这一项，导入后的版式与原稿一致。

## 三、正文的基本写法

- **一行一段**。段落之间空不空行都行。
- 标题：`# 1 总论`（一级，自动另起一页）、`## 1.1 项目背景`、`### 1.1.1 …`、`#### …`（四级不进目录）。编号自己写，程序会查是否连续。
- 加粗：`**要加粗的字**`。
- 上标、下标直接写成字符：m³、m²、SO₂、NOₓ、SF₆、CH₄。生成 Word 时程序自动把它们换成 Word 的上标、下标格式。不要写成 m3、SO2、NOx，也不要写 `<sup>`（不识别，会原样印出来）。
- 自动编号列表：行首写 `1. `、`2. `……；重新从 1 开始就是新的一组。不想被当成列表的“1.”开头的段，前面加反斜杠：`\1. ……`。
- 行首要写 `#`、`|`、`!` 这类符号时，前面也加反斜杠。

## 四、表格

```
表5.3-1  职业病防护设施符合性与合理性评价表
<!-- 表格 列宽=450,1150,3800,2400,1150,4280 字号=19 对齐=中,中,左,左,中,左 -->
| 序号 | 检查项目 | 标准要求及依据 | 可研拟采取的措施 | 符合性 | 合理性分析及补充要求 |
|---|---|---|---|---|---|
| 一、防尘防毒 | < | < | < | < | < |
| 1 | 通风 | …… | …… | 符合 | …… |
| ^ | ^ | …… | …… | 基本符合 | …… |
```

- 表题：紧挨在表格上一行（中间只能夹“表格”指令），以“表X.Y-Z”开头。表题自动居中加粗、与表格同页。
- 分隔行 `|---|---|` 之前的行都是表头（可以有多行表头），表头跨页自动重复。
- 合并：`^` 与上一格合并，`<` 与左一格合并（整行除第一格都是 `<` 就是分组行）。
- 格内换段写 `<br>`；格内要写竖线写 `\|`；格里真要写 ^ 或 < 时写 `\^`、`\<`。
- 表注：在表格下一行写以“注：”开头的段落。生成时自动排进表格最后一行，处理如下：
  - 整行合并，两端对齐，“注：”两字悬挂；
  - ②③…各起一段，与①对齐；
  - 与表格最后一行同页。

  表注不会和表分到两页。不要把表注写成表格里的一行，也不要在表和注之间夹横向、纵向指令（用户 2026-10-27 批注）。
- 表格前后的说明文字：讲数据来源、口径、估算的话，写成表注；讲因素和设施对应关系的长句，改成对照表（一类一行），正文只留一句“见表X”（用户 2026-10-27 批注）。
- “表格”指令（可选，写在表题和表格之间）：

| 选项 | 写法 | 说明 |
|---|---|---|
| 列宽 | `列宽=1,3,2` 或 `列宽=900,2700,1800` | 总和不超过 100 按比例分；否则按 twip（1 厘米≈567），超过版心宽自动缩 |
| 字号 | `字号=19`、`字号=五号`、`小五` | 数字是半磅（21＝五号，18＝小五）；默认五号 |
| 对齐 | `对齐=中,左,左,中` | 逐列写”中/左”；不写时按列名自动判断：序号、编号、符合性、适用性、限值、数值等固定词列居中；长描述列（防护措施、建议、依据条款）靠左；有疑义时显式写出覆盖自动判断 |
| 表后空行 | `表后空行=否` | 默认表后留一个小空行 |
| 不跨页 | `不跨页` | 整张表放在同一页 |
| 同页行 | `同页行=2,3` | 这几行与下一行不分页（分组行自动与下一行同页） |
| 其他 | `缩进=120`、`边距=上,下,左,右`、`居中`、`宽度=8300`、`表头行=0` | 一般不用写 |

## 五、图片

```
![项目总平面布置图](图/总平面布置图.png){宽=15cm}
图2.3-1  项目总平面布置图
```

- 图片单独一行；`{}` 里可写 `宽=15cm`、`高=10cm`（只写一个就按比例）、`段前=4磅`、`段后=4磅`；不写就按原图大小，最宽到版心。
- 图题紧挨在图片下一行，以“图X.Y-Z”开头。图题画在图片里的，可以不写图题行。

## 六、版面指令（单独一行）

| 指令 | 作用 |
|---|---|
| `<!-- 横向 -->` / `<!-- 纵向 -->` | 从这里起改横向／纵向页（宽表放横向页，写完切回纵向） |
| `<!-- 分页 -->` | 从这里另起一页 |
| `<!-- 空行 -->` | 空一行 |
| `<!-- 段落 居中 -->` | 下一段居中；还可写 `不缩进`、`左对齐`、`右对齐`、`与下段同页` |

其他 `<!-- …… -->` 都是写作提示（可跨行），不会出现在报告里。注意：不要把横向／纵向指令写在标题和正文之间，否则标题会孤零零留在上一页（检查会提示）。

## 七、自动计算（占位符）

正文里写占位符，生成时自动换成按表格算出的文字，改了表格不用再改正文：

| 写法 | 生成 |
|---|---|
| `{{计数:表5.3-1}}` | 表5.3-1共评价18项，其中符合5项、基本符合3项、按补充措施完善后符合10项 |
| `{{计数:表2.3-1:总体布局}}` | 总体布局共评价4项，其中…… |
| `{{行数:表9.2-1}}` | 表体行数（不算表头和“合计”行），如关键控制点个数 |
| `{{合计:表8.3-1:金额（万元）}}` | 某一列数字的合计 |
| `{{项目名称}}`、`{{建设单位}}` 等 | 项目信息.md 里对应的内容 |

计数规则：按“符合性”列（表头以“符合性”开头，或叫“判定／评价结果／结论”）逐行数，跳过分组行和合并续格；为 0 的档不写；只有一档时写“均判为××”。档位只能用：符合、基本符合、按补充措施完善后符合、无设置必要（第7章用“无配备必要”）。

## 八、检查规则.md

```
## 禁用
- `400 t`            ← 出现就报错（已纠正的旧数字、不适用的内容）
## 必备
- `表5.3-1共评价18项`  ← 必须出现
## 提示
- `设计专篇`          ← 出现时提醒人工确认
## 正则禁用
- `应(增设|加装|补设)`  ← 按正则表达式查
- `(?<!“)两个酸再生站`  ← 只拦引号外的旧说法（第2章资料口径差异引述原文时保留）
```

已纠正的旧说法、改掉的旧名称写进“禁用”，防止改稿时改回去；需要在资料口径差异里引述原文的，用“正则禁用”加 `(?<!“)`，只拦引号外的写法（`PL-PRE-0040`）。

## 九、生成后看什么

`输出/校验报告.md` 分四块：**错误**（必须改，如计数与表不符、档位写错、引用的表不存在、标准号连接号、括号不配对、禁用说法）、**提示**（人工确认）、**待办**（【待填】【待核】）、**自动计算的文字**（每个占位符生成了什么）。另有页数和目录页码复核结果。
