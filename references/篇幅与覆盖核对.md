# 篇幅与覆盖核对：改写用户原稿时防“改错变删减”

> 来源：晋钢200MW超临界煤气发电项目预评价（2026-10）。用户给了约11.5万字的原稿（有少量错误），要求改成本 skill 的格式。第一版由性能较弱的模型生成：纠错时连带删掉整节、整表，正文从约8.3万字压到约3万字（去重后计），表格从53张减到31张，成稿只有80多页。重做版逐章对照原稿后为约10.3万字、58张表。判例 `PL-PRE-0042`。

## 一、规矩

1. **纠错不等于删减**。原稿的每一节、每张表、每个检查条款都要有去向：保留、改写、合并、移到别的章，或删除并写明理由。
2. **能删的只有四类**：不实（如把未建成的项目写成“已制定十二项制度”“培训率达到100%”）、跨项目残留（如别的项目的空冷岛、石灰石-石膏）、已废止的依据、同一段文字的重复抄写。删了就在交稿说明或 `检查规则.md` 的“## 篇幅豁免”写理由。
3. **事实错改事实，口吻错改口吻**。把“已建立七类档案”改成第10章“应按《职业卫生档案管理规范》建立以下档案……”，不整段删掉。
4. **照抄条文的检查表，条款全留，只压缩表述**。原稿逐条全文抄《工作场所职业卫生管理规定》第八条至第三十七条，改写时每条都要在表8.2-1有一行或并入某一行，只把条文压成要点。
5. **原稿缺而标准要求的要补**：如原稿没有第9章关键控制点、第3章不确定度评估、第8章专项经费估算。
6. 正文不写“原稿”“本稿”“原报告”等编辑口吻（写进项目检查规则的“禁用”）。一章内容多可以拆成几个文件（`02_1_…md`、`02_2_…md`），按文件名顺序合并。

## 二、怎么做

1. **开工前盘点**：`import 原稿.docx 原稿项目`，把原稿转成项目文件夹；逐章列出节、表（表号、行数）、图、检查表条款范围，写成盘点清单。
2. **定去向**：清单每一项标“保留／改写／合并到…／移到第…章／删除（理由）”。
3. **写完每章就比对**：

```bash
python3 scripts/report.py coverage 原稿项目 新项目
```

结果写到 `新项目/输出/篇幅核对.md`。字数只数汉字、数字和字母；同一章里重复的段落和单元格只算一次（原稿常把同一句依据抄几十遍，不去重会误判）。章按章名对齐到 11 章，原稿是 10 章时第9章“补充措施”对新稿第10章。

| 结果 | 含义 | 怎么办 |
|---|---|---|
| 错误：字数低于下限（默认 80%） | 很可能删多了 | 逐节对照原稿找回；确属上面四类的，在 `检查规则.md` 写“## 篇幅豁免”，每行“- 第8章：理由” |
| 提示：表格数或表行数减少 | 合并、改写成段落也会这样 | 人工确认原稿的数据和检查条款都还在 |
| 提示：原稿没有对应的章 | 新增章 | 不比篇幅 |

4. **交稿前再跑一次**，全部章节达标或写了豁免理由。豁免只在低于下限时生效；后来补齐了就删掉豁免，免得掩盖以后的删减。

## 三、每章至少要有的内容（GBZ/T 196—2025 第10.2节，重做时逐项核）

| 章 | 至少要有 |
|---|---|
| 1 总论 | 背景；法规和标准清单（正文引用的都在清单里，清单里的都被引用）；基础技术资料；目的、范围、内容；方法（只列用了的）和方法应用表；程序图；评价单元表；质量控制（能力、资料审核、依据现行性、方案审核、调查、类比资料控制、报告审核、档案、评价结果控制） |
| 2 工程分析 | 基本情况表、区域位置图、气象和风向资料；项目组成、定员、技术经济指标；资料差异表；选址表和总体布局评价表、平面布置图；原辅材料表；各工艺系统流程图；生产工艺评价表；设备表和设备布局评价表；建筑卫生学表和评价表；车间卫生特征分级表和辅助用室评价表 |
| 3 类比调查 | 可比性对照表（附录C.1 九个方面）；调查内容表（C.2 a～f）；接触、防护设施、防护用品、应急、健康监护、管理的调查；检测结果表（只引原始数据并重新判定）；资料应用及不确定度表 |
| 4 危害因素 | 运行期因素分布及接触表、各工种接触表；劳动过程和生产环境因素；健康效应表（含急性中毒分级、潜伏期等临床要点）；预期接触水平与符合性预测表；无限值因素的情景分析或定性分析 |
| 5 防护设施 | 类别适用性表、各单元拟采取设施表、符合性与合理性评价表、小结 |
| 6 应急救援 | 逐个急性危害因素的危害特点和处置要点；组织、设施、处置措施和外部依托表；应急救援评价表、小结 |
| 7 防护用品 | 类别适用性表、各工种配备表、符合性评价表、小结 |
| 8 职业卫生管理 | 可研拟采取措施表；按《工作场所职业卫生管理规定》第八条至第三十六条逐条有落点的评价表；专项经费估算表；小结 |
| 9 关键控制点 | 判定依据表、关键控制点表 |
| 10 补充建议 | 可研和初设问题表；各专项建议；急救箱、职业健康检查、警示标识等专项表；“三同时”落实与验证清单 |
| 11 结论与建议 | 风险类别、主要因素、关键控制点、各单项评价结论、总体结论“有条件实施”；建议 |
