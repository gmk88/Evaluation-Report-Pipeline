# 编制流程与资料清单

## 一、编制流程

1. **收资料**：按下面的清单向建设单位要资料，放进项目的 `资料/` 文件夹；缺的记下来。
2. **建项目**：`python3 scripts/report.py new 项目文件夹 --名称 项目名称`。手上有同类项目的成稿，也可以 `import 成稿.docx 项目文件夹` 转成项目，在它基础上改（马沟已转好，在 `examples/马沟/`）。
3. **填项目信息**：`项目信息.md`（封面、人员、附件）。
4. **按章写正文**：顺序建议 2 工程分析 → 3 类比调查 → 4 危害因素识别与危害程度 → 5～8 各项评价 → 9 关键控制点 → 10 补充建议 → 11 结论 → 最后回头写 1 总论。每章怎么写看 `references/各章写法/`，判定口径看 `references/判定规则与口径.md`，易错点看 `references/常见错误与教训.md`。
5. **生成并查错**：`python3 scripts/report.py build 项目文件夹`。看 `输出/校验报告.md`，把“错误”全部改掉、“提示”逐条确认，再生成。数字（计数、关键控制点个数）尽量用占位符，改表后自动跟着变。
6. **交付**：`输出/` 里的 Word、PDF。附件（委托书、备案文件、图纸、检测报告）另行合订。
7. **积累**：项目里新踩的坑，写进 `references/常见错误与教训.md`；本项目的定稿数字写进 `检查规则.md` 的“必备”，已纠正的旧说法写进“禁用”，防止改稿时改回去。

## 二、资料清单（建设单位提供）

| 资料 | 用在 | 说明 |
|---|---|---|
| 职业病危害预评价委托书 | 1.1、附件 | 委托方、项目名称、日期 |
| 项目备案（核准、批复）文件 | 1.1、1.2、附件 | 项目名称、建设地点、规模、投资以此为准 |
| 可行性研究报告（含职业病防护内容） | 第2、5～8章 | 预评价的主要评价对象；可研写了的才叫“可研已明确” |
| 总平面布置图、区域位置图 | 2.2、2.3、附件 | 站址坐标、周边情况、功能分区、风向 |
| 工艺流程图、工艺说明 | 2.5、4.1、附件 | 危害因素来源、产生环节 |
| 主要设备清单（型号、数量、参数） | 2.6、4.1、5.2 | 噪声源、密闭性 |
| 原辅材料及产品（名称、用量、成分） | 2.4、4.1 | 化学因素识别依据 |
| 劳动定员、岗位、班制、作业方式 | 2.1、4.1、4.3、7.2 | 接触时间、接触人数 |
| 建筑物（结构、面积、通风、采光）及辅助用室 | 2.7、2.8 | 建筑卫生学、辅助用室评价 |
| 拟设职业病防护设施、应急救援设施、个人防护用品 | 第5～7章 | 逐项评价 |
| 职业卫生管理制度、机构、经费 | 第8章 | 管理措施和专项经费 |
| 类比项目资料（检测报告、职业健康检查、现场调查） | 第3章、4.3 | 写明类比项目名称、检测单位、报告编号、年份 |
| 当地自然条件（气象、地质、水文） | 2.2 | 引用来源要写清 |

## 三、报告章节与标准条款（GBZ/T 196—2025 第10.2节）

| 报告章 | 标准条款 |
|---|---|
| 1 总论 | 10.2.1 |
| （现有企业概况） | 10.2.2，只有改建、扩建、技术改造项目才设 |
| 2 建设项目工程分析 | 10.2.3 |
| 3 类比企业（项目）调查与分析 | 10.2.4 |
| 4～11 | 10.2.5～10.2.12（章名与标准逐字一致，程序会查） |
| 封面、目录、附件 | 10.2.13 预评价报告格式 |

## 四、与设计专篇、控制效果评价的衔接

预评价是“三同时”的第一份报告，后面的设计专篇、控制效果评价都要承接它的危害因素、关键控制点、补充建议。写法与时序见 `references/三报告衔接.md`。
