# 06_条款规则 / 章节生成规范 —— 章程层

## 这一层解决什么

`知识库/评价各章节分阶段判定标准矩阵.md` 回答的是**「这一章该看哪些标准」**——横向的
「章节 × 阶段 → 标准号 → 判定重点」。

它不回答**「这一章的每一句话要从哪条来、要回答到什么程度、写到哪算够」**。

缺的正是这一层。而缺它的代价是实打实的：2026-10-03 用户对马沟第3章连提四条纠正，
根因不是写错字，而是**GBZ/T 196—2025 第10.2.4 条与附录 C 的要求从来没被转成可逐条核对的
生成规范**，只停留在一份 `_work/` 底稿里（判例 `PL-GEN-0028`）。

所以本目录放的是**规范的、可逐条核对的章节生成要求**。

### 关于 `范例_*` 的例外

`范例_` 开头的文件**故意带项目事实**（站名、地址、编号、人名、数值）——它的用处就是当"标尺"，
让人看见"写足了是什么样"，脱离项目事实就没法对照。这是本目录唯一的例外：

- 规范文件里**不得**出现项目事实（出现即串味，改写成指向项目记忆的指针）；
- `范例_*` 里**必须**是真实项目事实（否则标尺无意义）；
- 换项目时**不要复制 `范例_*` 到新项目**——格式照规范，内容重写。
  文件名带项目名就是为了让这一步不容易错。

## 怎么用（动手改某章之前）

1. 打开 `全局《职业卫生报告执行规范》→ 章节生成规程`，先走第一步「取导则要求」；
2. 到**本目录**取该章的生成规范；没有就按下面的格式补一份——**不要跳过这步直接开写**；
3. 取该章的 `第<N>章_标题结构.md`，先确认**每个 R 项挂哪个标题**；
   标题结构还没有的，先补结构再动笔——否则 R 项会散落在正文里，事后核不出来；
4. 规范里的 R 编号要求项逐条落到正文或表格，改完用规范末尾的自检清单核；
5. 这一章若涉及项目口径，再读 `.workbuddy/memory/MEMORY.md` §1.2 该章那一行指向的分册。

## 新增一份章节生成规范

文件名：`第<N>章_<章节名>_生成规范.md`（章号与报告骨架一致，不按矩阵专题号）。

必备六节，缺一不可：

1. **依据**——明示条号（阶段主文件的哪一条）＋被援引的附录条款号；
   **依据层级只有三类**：评价通则（共性底限）／阶段技术标准（设不设、写什么）／库内判定底表与项目规范。
   **编制要求类文件（ZW-JB 系列）只作参考项，可执行可不执行**——不列为依据、不设要求项、
   报告依据清单里也不列（判例 `PL-GEN-0033`）；
2. **要求项清单 R1…Rn**——每项写清「依据条号／要求实质／必须落在报告的哪个位置」；
3. **小节结构与判定档位**——每小节的必答问题、证据来源、输出形式、判定档位；
4. **必备表格**——表号、行、列、列宽合计（本报告纵向 8186 dxa）；
5. **禁止事项**——标准条文照抄、与邻章职责串味、把拟采取措施写成已执行事实等；
6. **自检清单**——可勾选，逐条对应 R 编号。

**另配一份 `第<N>章_标题结构.md`**（可不写，但写了才闭环）：把 R1…Rn 逐项挂到三级标题上，
并写明「哪个标题挂哪张表 / 与报告现状的差异 / 落到报告要付出什么代价」。
**只有 R 清单、没有标题落点，规范就是悬在空中的**——见 `第3章_标题结构.md` 的开头说明。

## 位置说明（为什么放在 `06_` 而不是 `09_模板与输出`）

`职业卫生评价知识库建设方案.md` 的计划目录里，最接近的两个是
`06_条款规则/`（条款记录、章节矩阵、检查表、判定规则）与
`09_模板与输出/`（报告引用模板、检查表、证据缺口表）。

选 `06_` 的理由：

1. **性质**：章节生成规范做的是「把条款转成逐条可核对的生成要求」，与 `06_` 已有的
   条款记录、章节矩阵、判定规则是同一件事的不同颗粒度，不是"模板/输出"。
2. **不占用编号**：`09_` 尚未建立，且知识库存在 `05_` 编号占用的未决问题
   （见建设方案「现状对照」）。新建 `09_` 会把编号问题一起放大。
3. **可回溯**：放在 `06_` 下，与章节矩阵同处一目录，从矩阵跳转规范是相邻关系。

若将来 `09_` 建立并收拢全部输出规范，本节可整体平移——届时只需改本文件与矩阵里的
两条引用。

## 边界

- **本目录只放规则，项目事实留项目记忆**（同 `编制技能路线图.md` 的 L2/L3 边界）。
  规范里出现「本站」「马沟」「2026 年」这类项目事实就是串味，应改为指向
  `.workbuddy/memory/MEM/` 或 `马沟预评价项目记忆与工作交接.md`。
