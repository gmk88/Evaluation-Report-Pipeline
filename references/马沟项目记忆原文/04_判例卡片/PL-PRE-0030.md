# 设施的设／不设以评价章判定为准，全文（含其他章表格旧表述）一次改齐

> 一条判例只讲一件事。写不成一句话的，拆成两条。

## 触发场景

第6章表6.3-1 把应急喷淋洗眼设施判为「无设置必要」，理由是可研/项目不具备
`GBZ 1—2010 第8.3条` 的两个触发条件（化学性灼伤、经皮肤黏膜吸收引起急性中毒）。
但同一份报告的其他章仍写着要设冲洗设施，来源是设计专篇的口径。

## 做法

**错误做法**：只改了第6章和 §1.2.2 的标准清单，其余五处不动。结果是同一份报告里
「无设置必要」与「设置低温冲洗点1处」并存。

| 位置 | 原表述 |
|---|---|
| §10.2.6 | 在事故影响范围外的安全区设置**低温冲洗点1处**，落实防冻、清洁水源、可达性和夜间识别条件 |
| §10.5.4 | 低温冻伤急救所需的**适温清洁水源和冲洗条件**应进行专业设计 |
| 表10.1-1 | 「采暖通风、**应急冲洗**等」「急救/**冲洗**」 |
| 第4章危害因素表 | 「可研对局部防护和**应急冲洗**不具体」「操作站位、**应急冲洗**/急救用品」 |

**正确做法**：

1. **定优先级**：以评价章判定为准，对策措施建议章只能承接。
2. **横扫全文**：正文小节、小结、其他章正文条目、其他章表格里的旧表述，一次改齐。
   表格里的旧表述最容易漏——它没有数字编号，肉眼扫目录时看不见。
3. **保留标准原文**：`GBZ/T 196—2025 第10.2.7条` 列举的「冲洗设备」、
   `GBZ 1—2010 第8.3条` 列举的「不断水的冲淋、洗眼设施」是条文原文，必须照录。
4. **删了要补**：用评价章认可的替代措施补位，不要只删。

本批替换结果：

| 位置 | 现表述 |
|---|---|
| §10.2.6 | 配备低温冻伤急救用品和洗眼液，存放位置应便于取用，并在专项应急预案中明确低温冻伤的复温处置要求和送医程序 |
| §10.5.4 | 低温冻伤急救用品和洗眼液应结合作业岗位布置存放位置…；低温冻伤的复温处置要求应在专项应急预案中明确 |
| 表10.1-1 | 「报警、联锁、切断、放散、隔声减振、采暖通风等」「补充检测、空气呼吸器、风向标、急救用品、疏散和专项演练」 |
| 第4章危害因素表 | 「可研对局部防护和现场急救用品的配置不具体」「低温表面隔离、接头残液控制、操作站位、现场急救用品」 |

## 依据

- 用户：2026-10-03「目前我们确定的第6章优先级最高，全文不一致的地方都需要遵循，
  所以要与第6章口径一致」＋处理方式选「删设施要求，改急救口径」
- 规范：`GBZ 1—2010` 第8.3条（判定门槛，见 `PL-PRE-0024`）
- 项目：被替换的六处原文位于 `mago_original.docx` 段落下标 894／895／1044／1157／1182／1195

## 可复用规则

> 设施设与不设的口径以评价章的判定为准，对策措施建议章只能承接；定下口径后要在
> 全文（含其他章正文与其他章表格的旧表述）一次改齐，标准原文引用除外，删掉的设施
> 要求必须用评价章认可的替代措施补位。

## 反例或例外

标准条文原文不属「不一致」。其他章引述建设单位已有文件现状时可保留原口径，但要注明来源。
对策措施建议章与评价章的建议**重合**是允许的，本条管的是**冲突**不是重复。
同一措施在本章内的横扫见 `PL-PRE-0027`。
