# 已建成项目：实物已定的参数，全文不得再写成「待后续统一」

> 一条判例只讲一件事。写不成一句话的，拆成两条。

## 触发场景

预评价的评价对象是**可研阶段工程方案**，但项目往往**已经建成投产**。
两者的工程内容一旦不一致（马沟：可研 2 台双枪，实际建成 2 台单枪），
报告里就会出现两类错：

1. **宣称「按可研方案建成」**——3.1 首段原写「本项目站址已按可研方案建成投产，
   运行期现状与可研方案同址，具备天然可比条件」；
2. **把已被实物定死的参数，仍写成待后续阶段确定**。

第 2 类是隐蔽的：单看一句都对，但它假设了「还没建成」。

## 错误做法

一句话挑出的毛病，横扫发现是 10 处：

| 位置 | 原表述 | 为什么失效 |
|---|---|---|
| 3.1 首段 | 本项目站址**已按可研方案建成投产** | 实际是单枪；且与表3.1-1 差异栏自相矛盾 |
| 表2.1-4 注 | 加气机枪数…**应在施工图和采购文件中统一** | 施工图、采购已完成 |
| 表2.6-1 备注 | **统一单枪或双枪配置** | 已经建成，无须「统一」 |
| 表2.6-2 | **双枪**加气…**需按双枪同时作业**核验 | 实际单枪作业 |
| 表5.1-1 | 按**最终单/双枪设备**确定释放源 | 已无「最终」可言 |
| 表9.2-1 | **最终枪数统一**，拉断阀… | 同上 |
| 表10.1-1 | 单枪/双枪口径未统一…**P1/施工图前** | 责任阶段已过去 |
| 第10章建议 | 在施工图和采购文件中**统一** 2 台的参数 | 同上 |
| 表10.8-1 | **统一**加气机枪数…责任阶段＝设计/施工图 | 同上 |
| 11.1 结论两条 | **应在施工图和采购文件中统一**能力参数；**设计阶段应统一**枪数 | 同上 |

## 做法

**正确做法：**

1. **可比性的支点只写站址与工艺类型**，不写「按可研方案建成」：

   > 本项目已建成投产，运行期现状与可研方案处于同一站址，介质、生产工艺和生产设备
   > 属同一类型，具备天然可比条件；两者在设备规格和部分计算口径上存在差异（见2.1.6）。

   维表末句同时改为「差异及其影响一并列于表3.1-1」，与表头「差异及其对本报告的影响」栏呼应。

2. **实物已定的参数一律改按实际值陈述**（「实际已按单枪建成」「按实际建成的 2 台单枪设备确定…」）。
3. **责任阶段与优先级跟着事实走**：表10.1-1 由「P1/施工图前」→「P1/设计与运行」；
   表10.8-1 责任阶段由「设计/施工图」→「设计/控制效果评价」。
4. **可研口径的表保留可研值，但必须显式标注**：列头已写「可研规格及主要参数」的
   （表2.6-1），规格栏留「双枪」只补备注；列头没有口径标注的（表2.1-2），
   改写为「LNG加气机2台（可研为双枪，实际建成单枪）」。
5. **差异写在一处**：集中放 §2.1.6 表2.1-4 下注与表3.1-1，其余位置只指向，不复述一套数。
6. **只改该事实的直接结果**：设计能力口径（4×10⁴ 与 2×10⁴ Nm³/d）属另一个独立问题，
   用户未确认，本轮不动。

## 可复用规则

> 项目已建成投产时，凡把某个已由实物确定的参数写成「待后续施工图／采购／设计统一或确定」
> 的表述全部失效，必须改写为按实际建成值陈述；可比性论证的支点只写站址与工艺类型相同，
> 不得宣称「按可研方案建成」；可研口径表可以保留可研值，但必须显式标注口径，
> 并在备注或下注写明实际值与差异落点。

## 反例或例外

- **不要反向越界**：仍应由设计确定的参数（探测器布点、报警点表、拉断阀、应急设施）
  继续写「应在职业病防护设施设计中明确」；改的只是已经被实物定死的那几项。
- **评价对象仍是可研方案**：防护设施要求按可研工况提（含裕量），
  不因实物是单枪就把要求降到单枪。本条改的是事实陈述与责任阶段，不是设计基准。
- 同一组数在不同章节有多个口径（设计能力 4×10⁴ 与 2×10⁴ Nm³/d）而原因未核实时，
  只把枪数这一项改齐，其余留在不确定度表等核实，不趁手一起改。
