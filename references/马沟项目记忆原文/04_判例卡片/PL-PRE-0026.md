# 引标准条文前，回原文逐字核条号；核不到就写标准名、不写条号

> 一条判例只讲一件事。写不成一句话的，拆成两条。

## 触发场景

第6章 表6.3-1 是五列符合性评价表，第二栏「标准要求」整栏按「GBZ 1第X条：原文」的格式写。
十一处条号全部对不上原文，其中五处引的是标准里不存在的条款。这不是笔误，是**凭主题印象
回忆条号**的必然结果——想起「应急救援」就往「看起来像应急救援」的章节挂。

## 做法

**错误做法**（本例实测）：

| 报告原写 | 实际 |
|---|---|
| GBZ 1 第7.1.1／7.1.2／7.1.3／7.1.4 条 | 第7章是「辅助用室基本卫生要求」，应急救援在第8章 |
| 第7.1.3条「定期组织应急演练，每年至少1次」 | GBZ 1 全文没有「演练」二字 |
| 第5.1.5.7条「生产车间安全出口不应少于2个」 | 全文没有「安全出口」「疏散」；5.1.5 讲区内交叉污染 |
| 第5.1.4.5条（事故通风） | 5.1.4 是选址风向；事故通风在 6.1.5.2 |
| GBZ/T 205 第5.2.1／5.2.4 条 | 第5章只有 5.1～5.12 平铺条款，没有二级编号 |
| GBZ/T 223 第5.1条（可燃气体报警） | 5.1 是「报警值设定原则」；且该标准第1章范围**只管有毒气体** |
| GB 39800 附录E（低温防护服） | GB 39800.1—2020 只有附录 A/B/C，GB 39800.2—2020 只有附录 A/B |

**正确做法**：

1. **按来源分三类核**——
   库内有文本层的（GBZ 1—2010、GBZ/T 196—2025）：抽「以编号开头」的行成条款清单，再取全原文逐字对；
   库内是扫描件的（GBZ/T 223—2009）：170 dpi 渲染成 PNG，**用多模态逐页读**；
   库内没有的（GBZ/T 205—2007、GB 39800.1/.2—2020 只有 N0 缺口卡片）：取官方原文再引。
2. **两验**——先读**第1章范围**判适用性（「有毒气体」标准支撑不了可燃气体要求），
   再读**目次**判章节与附录是否真的存在（避免「附录E」这类凭空造）。
3. **关键词计数**当证伪工具——怀疑某条不存在，就把该名词在全文数一遍，为 0 即证明。
4. **核不到就降级**——只写标准名称与版本＋概括要求，不写条号；不凭印象补。

## 可复用规则

> 符合性评价表里每一条「标准号＋条号＋原文」，都必须回该标准的原文逐字核过才写；
> 核不到原文的条号宁可不写，也不能凭主题印象补。

## 反例或例外

只写标准名称不写条号时不需核到条；概括性引用核到条标题即可。
已交付报告里发现同类错误时，要连带改「依据标准清单」和「小结」中同一批标准的出现处。
