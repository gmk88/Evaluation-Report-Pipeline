# 三报告衔接（预评价 → 设计专篇 → 控评）

> 三个 skill 共用本文件。马沟加气站的实例在文末。依据判例：`PL-GEN-0046`～`0051`、`PL-GEN-0054`、`PL-DES-0001`、`PL-CTL-0002`。

## 一、时序和引用：前不引后

| 阶段 | 报告 | 能引用 | 不能引用 |
|---|---|---|---|
| 可研阶段 | 职业病危害预评价报告 | 可研、立项文件、设计图纸、消防设计等时序在前的文件、现场调查、检测和体检报告 | 设计专篇、控评（只能作为“后续应……”的对象出现） |
| 设计阶段 | 职业病防护设施设计专篇 | 预评价报告（逐条采纳）、设计文件、施工图、检测资料 | 控评；不写“控制效果评价前完成”一类时序要求 |
| 竣工验收前 | 职业病危害控制效果评价报告 | 预评价报告、设计专篇（并核对其措施落实情况）、检测、体检、管理资料 | — |

- 已建成项目补做三同时（马沟就是）：三份报告日期也要守住上面的先后顺序；委托书日期按时序预填，写明“可按实际调整”。
- 检测任务编号和报告编号不要混用（马沟：检测任务 AT-2026-K013（1），控评报告 AT-2026-K013）。

## 二、共用事实表（每个项目开工就建）

三份报告必须一致的事实，先列成一张表，三份报告都从这张表取值：

| 事实 | 说明 |
|---|---|
| 委托单位、建设单位 | 两者可能不同（马沟：委托单位是上级分公司，建设单位是备案证上的项目单位）；写法统一 |
| 站址（厂址）、经纬度、区域位置图 | 设计专篇须写经纬度并附区域位置图（WS/T 882—2013 附录B.1 d）；三份报告用同一张位置图 |
| 规模、产量或经营量、工作制度 | 以建设单位确认值为准，可研值要标明“可研” |
| 定员、岗位、班制 | 类比项目定员也要核 |
| 总平面方位 | 以施工图为准，方位词逐一核对 |
| 主要设备、防护设施数量 | 如探测器个数、检测仪台数、更衣柜和淋浴器数量 |
| 投资 | 预评价是估算；设计专篇按费用类别列；控评引设计专篇口径 |
| 检测资料 | 检测任务编号、采样日期、报告日期、检测依据版本 |
| 日期 | 委托日期、报告日期、评审日期，守住时序 |

## 三、一致性核查表

- 发现三份报告之间的不一致，**先写进核查表**，再改报告；不要只改一份。
- 表头：序号／事项／预评价写法／设计专篇写法／控评写法／依据／处理建议／责任方（评价组、建设单位、检测机构）／处理结果。
- 序号一旦给出就不变，新增项接在后面。
- 需要建设单位、检测机构确认的事实，不臆造，写“待……确认”，列入签发前待办；不替对方改原件（如检测报告单由检测机构更正）。
- 用户回答“其他没问题”“其他同意修改”时，先把“其他”指哪些项列出来请用户确认，再动手（`PL-GEN-0049`）。

## 四、承接关系

- **设计专篇对预评价**：对预评价提出的对策措施逐条说明采纳情况（采纳／调整采纳／不采纳），调整和不采纳要写理由（WS/T 882—2013 第7.4.6条）；已建成项目以施工图和已建成设施为准，不提新增工程整改（`PL-DES-0001`）。
- **控评对前两份**：补记预评价和设计专篇的编制情况、列入评价依据，并单设一节核对其措施落实情况（马沟控评第2.3节、表2.3-1 逐项核对设计专篇调整采纳的措施；采纳的措施落实情况引到各章）（`PL-CTL-0002`）。
- 不设某项设施的理由，在三份报告里不得互相否定（`PL-GEN-0047`）。

## 五、签章、日期、第三方事实

- 印章、签名、评审意见不臆造；日期按时序预填并标明可调整（`PL-GEN-0050`）。
- 附件原件和正文写的标准版本不一致时，请出具方核实，不自己改（`PL-GEN-0051`）。

## 六、版本和并行会话

- 每出一版另建新目录和新包，旧包不改；包一出就上传（会话文件、Notion），沙箱会回档（`PL-GEN-0045`）。
- 定稿前盘点有没有别的会话做过的成果（会话文件、Notion 附件、各包说明）；有就先合并，再出新版；编号撞了，后并入的一方改号并全文同改（`PL-GEN-0054`）。
