# WPS 命令行只认嵌入字体：裁剪嵌入、两轮导出、导出后查字体

> 一条判例只讲一件事。写不成一句话的，拆成两条。

## 触发场景

用户定了出 PDF 只用 WPS 命令行。第一次导出页数、目录都对，中文却全是苹方。

## 错误做法

- 页数、目录核对通过就交付，不看字体。
- 装字体、改字体名，指望命令行按名字找到。
- 整份嵌入大字体文件，或只嵌中文、不嵌 Times New Roman。
- 遇到问题就问用户换导出方式。

## 正确做法

| 步骤 | 做法 |
|---|---|
| 渲染副本 | 每轮从核对版另存一份，嵌入裁剪后的仿宋、宋体、Times New Roman 常规和粗体（约 1.2 MB）；交稿 DOCX 不嵌 |
| 第一轮 | 导出 → 查字体和插图 → 按 PDF 回填目录页码和“共N页” |
| 第二轮 | 用回填后的 DOCX 重做渲染副本 → 导出 → 查字体和插图 → 逐页核对目录页码、PDF 目录上印的页码和页脚 |
| 发布 | 核对通过才把 DOCX 和 PDF 放进 输出/，原来的先存一份 |

命令：`python3 scripts/report.py wps 项目 --发布`（不加 `--发布` 只出核对文件夹）。

## 可复用规则

WPS 命令行只认嵌在 DOCX 里的字体：每轮把用到的字体裁剪后嵌进渲染副本再导出，两轮回填核对，导出后查字体和插图；交稿 DOCX 不嵌字体。
