# 避免生造四字格词汇，用具体工作流程替代

> 描述调查记录方式时，不要为了显得规范而生造"一事一记、一图一注"这类词汇。
> 从业者自己都看不懂的表述，审查专家和建设单位更无法理解。

## 触发场景

在 1.9.4 职业卫生调查章节中，需要描述现场调查记录的规范性和详细程度。
原稿写作"调查记录采用'一事一记、一图一注'的方式"。

## 做法

**错误做法**：
```
调查记录采用"一事一记、一图一注"的方式，对建设项目选址、
总平面布置、生产工艺流程、设备布局、职业病防护设施设置等
关键信息进行详细记录与标注。
```

这种表述存在的问题：
1. "一事一记、一图一注"是生造词汇，无行业规范依据
2. 从业者都不清楚具体含义
3. 审查专家和建设单位更难理解
4. 为了对仗而造词，形式大于实质

**正确做法**：
```
调查过程中对建设项目选址、总平面布置、生产工艺流程、设备布局、
职业病防护设施设置等关键信息进行详细记录，现场拍摄的照片、测绘
的图纸均进行编号与说明标注。
```

改进之处：
1. 直接描述实际工作内容："详细记录"
2. 明确说明图件处理："照片、图纸均进行编号与说明标注"
3. 每个人都能理解，不需要猜测含义
4. 符合实际工作流程：看-记-拍-标注

## 依据

- 用户：批注原文"'一事一记、一图一注'我作为从业者都不清楚什么意思"
- 原则：技术报告应清晰表述实际工作流程，不应为追求对仗或形式感而生造词汇

## 可复用规则

描述工作流程时，避免生造四字格、口号式词汇（如"一X一X"、"双X双X"），
改用具体动作描述实际做法（记录什么、怎么编号、如何标注）。

## 反例或例外

以下情况可以使用四字格或固定搭配：

1. **行业通用术语**：
   - "三级审核制度"——GBZ/T 196 等标准明确要求
   - "闭环管理流程"——质量管理常用术语
   - "三同时"——《职业病防治法》法定术语

2. **有明确规范依据的表述**：
   - "双重审核机制"——对应"内部审核+外部确认"
   - "一岗双责"——安全生产管理法定术语

3. **判断标准**：
   - 有标准或法规明确使用 → 可保留
   - 行业内通用且含义明确 → 可保留
   - 自己创造的对仗词汇 → 必须删除
   - **关键测试：如果从业者都不懂，就不能用**
