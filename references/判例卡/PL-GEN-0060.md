# 待补资料清单不进报告；资料只收集到能下结论为止

> 一条判例只讲一件事。写不成一句话的，拆成两条。

## 触发场景

两份报告第11章都有一张13行的待补资料清单，第2章两张表还有“需补充的资料”列。用户说这样“给人的感觉报告不完善”，要的东西太细、跟职业卫生不直接相关，“报告闭环难度太大”。

## 错误做法

- 报告里列待补资料清单，或在表里设“需补充的资料”列。
- 向建设单位要设备参数、建筑面积、储罐容积、作业频次、统计站点和年份等细节。
- 把用地历史、土壤状况、厂区权属、环评卫生防护距离、周边村庄方位距离列为要收集的资料。
- 按“影响不影响判定”决定“未给出”“未定”留不留：可研没写的评价发现会被删，“由设计单位确认”这类等人确认的说法反而留下。

## 正确做法

| 情况 | 写法 |
|---|---|
| 要检测才能定 | 写成检测要求，如“以投产前游离SiO₂检测结果确定” |
| 设计阶段才能定 | 写成设计要求，如“设计阶段确定点火燃料后，在职业病防护设施设计专篇中识别相应的职业病危害因素并落实防护措施” |
| 不会改变判定的资料 | 不收集、不追、不列，照可研和不利情况写 |
| 确需建设单位提供的少数几项 | 写在交稿说明里，不进报告 |
| 未作风险评估的因素 | 第9章写处置：按一般管理要求控制，设备内部作业时并入相应关键控制点；不写“待补评” |
| 可研没写到的（评价部分） | 写成“可研没有写／没有明确／没有给出……”，前后不一的写“可研××写法不一”，后面跟判定或补充措施；不清，也不写“未定”“可研未给出” |
| 等建设单位、设计单位提供或确认的 | 全清：写成设计阶段或投产前要做的事，或指向第10章相应条款；不写“资料未提供”“未取得”“由设计单位确认”“确认后”“待取得”“资料不足” |
| 描述表里只剩“未给出”“未定”的格 | 写“—”或删掉这一分句；括号里的“推断”“如使用”“暂定”不跟着删；删了表注的，后面的注改号，正文引用同步改 |

判断要不要收集：这项资料会不会改变危害因素、接触人员、接触时间或防护设施的判定。不会的，不收集。缺口怎么写，看缺的是谁，不看影响不影响判定。
