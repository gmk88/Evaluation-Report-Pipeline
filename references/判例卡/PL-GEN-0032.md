# 第4章各小节只放本小节内容：识别写识别、评价写评价、引言不抄表，设施与要求归他章

> 一条判例只讲一件事。写不成一句话的，拆成两条。

## 触发场景

危险性分析类报告的第4章要同时干两件事：列表（危害因素分布及接触预测）和叙述（运行期／生产环境中
职业病危害因素识别）。两处的边界一样——**只放识别内容**。边界一松，评审最容易在这里提问。

## 做法

### 一、表的「来源」列：写“如何产生”，不写名词罗列

马沟原稿 6 格全为名词罗列：

| 行 | 原稿「来源」 | 问题 |
|---|---|---|
| 卸车软管连接、拆除 | 接头残液、密封失效或误操作 | 有部位有原因，但没说清「怎么产生」 |
| 储罐及泵撬巡检 | 阀门/法兰泄漏、低温部件、泵运行 | 三个因素混写，未与噪声/低温/甲烷对应 |
| 车辆加注 | 加气接头、软管、车辆、**设备和露天环境** | 「露天环境」不是来源项 |
| 营业厅值守 | 外部车辆和设备传声、空调采暖 | 缺「运行」这一产生动作 |
| 配电室巡检 | 电气设备 | 只点设备，不点噪声由运行产生 |
| 空压机房巡检 | 空压机运行 | 同上 |

改为「过程＋机理」式简述：

| 行 | 改写后 |
|---|---|
| 卸车 | 卸车接头拆装时残液挥发、密封失效造成泄漏 |
| 巡检 | 阀门法兰密封处泄漏、泵撬运行噪声、低温部件冷损 |
| 加注 | 加气接头和软管拆装时残液挥发、车辆及设备运行噪声 |
| 营业厅 | 站外车辆及设备运行传声、空调采暖设备运行 |
| 配电室 | 配电设备运行时产生噪声 |
| 空压机房 | 空压机运行时产生噪声 |

### 二、识别段落：不写设施配置

马沟 4.1.3「生产环境中职业病危害因素识别」原文两分句是识别内容（室外场所→高温、低温；
室内场所→采光、照明），末句「营业站房设空调采暖」是设施配置描述，与识别无关，已删。
采暖/空调设施在第2章 2.7 建筑卫生学（表2.7-1）与第10.5 建筑卫生学补充建议中已有评价，
删掉不丢信息。改后段末收在「……等建筑卫生学因素。」。

### 三、4.3 评价小节：不写控制要求（2026-10-04 补案）

用户对 4.3.2 的批注是「**只做风险评估，不要搞控制要求**」，随后又指示「**4.3 内控制口吻一并改为评价口吻**」。
本轮实际清掉的位置：

| 位置 | 改前（要求口吻） | 改后（评价口吻） |
|---|---|---|
| 表4.3-1 甲烷行「预期符合性」 | 按泄漏积聚和缺氧防控要求评价；**需落实**密闭、通风、检测报警、紧急切断及救援防护。 | GBZ 2.1 未规定甲烷职业接触限值，**不作符合性判定**；正常运行时密闭储存和输送可使介质逸散受控，接头拆卸、检维修及异常泄漏可形成短时高浓度接触，其缺氧窒息风险按 4.3.2 作情景评价。 |
| 表4.3-1 低温行「预期符合性」 | 按保冷隔离、残液处理、操作防护和应急处置条件评价；**需落实**低温及眼面防护。 | GBZ 2.2 未规定 LNG 低温介质接触的单一职业接触限值，**不作符合性判定**；局部冷伤风险与连接拆卸、残液喷溅、泄漏及低温表面直接接触相关，按接触方式和防护条件评价。 |
| 4.3.1 正文（限值口径段末） | 放空作业为噪声重点控制环节。**设计应补充**设备声学参数、测点距离和岗位接触时间，**细化**消声、隔声、人员隔离和护听措施，并在代表性运行工况下验证岗位接触水平。 | 放空作业为本项目的噪声重点环节。可研未给出设备声学参数、测点距离和放空持续时间，运行工况下的岗位接触水平尚需在代表性工况下检测验证。 |
| 4.3.1 正文（环境高低温段） | 露天卸车、加气和巡检岗位受季节性高温、低温及恶劣天气影响。**应设置**遮阳防雨、饮水和室内休息条件，按天气情况调整连续作业时间，**落实**防暑、防寒措施。 | 露天卸车、加气和巡检岗位受季节性高温、低温及恶劣天气影响。该因素属环境气象条件，与 LNG 介质接触引起的低温危害成因不同；其危害识别与不作重点评价的理由见 4.1.3。 |
| 4.3.3 段末 | ……测定后确定。**甲烷按缺氧窒息风险控制，LNG 低温按局部冻伤及喷溅风险控制。** | 删去末句——4.3.3 只讲噪声作业分级，甲烷与低温的评价去向已在 4.3.2 给予。 |

三条要点：

1. **「预期符合性」栏不是措施栏**。该因素没有国内限值时，正确写法是「**不作符合性判定**＋简述实际控制状态」，
   而不是借这一栏提出措施——不然列头与内容又对不上（同 `PL-GEN-0023`）。
2. **评价段落的收笔方式是「还差什么」**，不是「应当做什么」。4.3.1 把「设计应补充…」换成
   「可研未给出…，尚需在代表性工况下检测验证」，既保留了证据缺口（`PL-GEN-0018`／禁止事项 8），又不越到措施章。
3. **删之前先确认别处有承接**（见反例或例外），删完**回扫整节**——本轮控制口吻散在 5 个位置，
   只改被圈选的那一处会留下四处矛盾（同 `PL-PRE-0027`／`PL-PRE-0030` 的「改口径必须横扫全文」）。

### 四、引言：不复述表格内容（2026-10-04 补案）

用户对 4.1 引言的批注是「**引言写的太啰嗦，时空分布不是这么写的**」。原引言三句的第三句：

> 危害因素在空间上分布于天然气罐区、加气区、营业厅、配电室和空压机房，在时间上与卸车、车辆加注、
> 设备巡检和营业厅值守等作业时段相对应。

问题：表4.1-1 表名即《运行期职业病危害因素**分布**及**接触**预测》，其「工作场所」列已列全这五个场所、
「作业内容」列已列全这几类作业，引言把它们复述一遍；且「在空间上…在时间上…」是教科书式定义句。
依 196 §10.2.5.1「应用选定的评价方法，明确生产过程中存在的职业病危害因素以及**时空分布**」，
R11 的落点是「表4.1-1 与正文的衔接句」。

改后（三句压两句，末句作衔接句）：

> 本节在第2章工程分析的基础上，按第1章表1.8-1划分的评价单元（卸气系统、加气系统、辅助生产系统）
> 逐单元识别职业病危害因素及其来源。评价范围以项目投产后运行期为主，建设施工与设备安装调试阶段
> 不纳入本次识别。危害因素及其工作场所、接触时间与频度的分布见表4.1-1。

判据：**引言里出现的场所名，若表4.1-1「工作场所」列已有，就是复述，删。**

## 可复用规则

> 危害因素识别表和识别段落只放识别内容：表「来源」列写「如何产生」——过程＋机理、
> 与该行所列危害因素一一对应，不写部件／设备／环境名词的罗列；
> 段落只讲会接触什么、怎么接触，不写设施配置与管理做法。

## 反例或例外

- 表下注、气象数据来源、检测资料出处这类「来源」是说**数据从哪来**，不适用本条（见 `PL-GEN-0030`）。
- 同表已有「作业内容」列说明「做什么」时，来源列不要重复它，只补「由此产生什么」。
- 该列列宽窄，改写后要复核表格是否因行高变化而重排、跨页位置是否仍合理。
- 删设施描述前先确认它在别处有承接，**删重复≠删信息**；若无处承接，先移入工程分析或建议章再删。
- **引言承诺的评价内容，表里必须真有；表里没有的指向要改指到真正写了它的那一章**（2026-10-04 用户「表4.3-2跟这里写的不一致」）：
  核对办法＝把引言里点名的**每一本标准、每一张表**与那张表／那一章的实际内容逐项对一遍。
  本次错在：4.3.2 引言写「并依据 GBZ/T 205—2007《密闭空间作业职业危害防护规范》评价受限空间作业条件，评估过程与结论见表4.3-2」，
  但表4.3-2 四个环节行全是 GBZ/T 298 的内容、全表一处 GBZ/T 205 也没有，「受限空间」只在两行**评价内容**里各出现一句；
  GBZ/T 205 的实质评价（检测报警、防护、应急救援）在**第6章**。改法＝**拆开指向**：情景分析见表4.3-2，受限空间要求指向第6章，标准依据仍留在引言。
  写「见表X-1」前先问一句：**那张表里真的有这句承诺的内容吗？**
- **「预期符合性」这类判定列，格内必须是判定，不是要求**（2026-10-04 用户「这里还偏」）：
  ① 有国内限值的因素要**给结论**——「2026年类比岗位结果低于相应限值，预期正常运行工况下岗位接触水平可符合 GBZ 2.2—2007 的 85 dB(A) 要求。」；② 无国内限值的写「不作符合性判定」＋简述实际控制状态（同卡已有的规则）；
  ③ **不准写「预计…需结合设备组合和接触时间验证」「需…后确定」**——那是待定语＋要求句，列头问的是符合性、格内答的是「还没结论」，读者要跨到正文才知道本次做到什么程度。验证条件写在正文（如 4.3.1「尚需在代表性工况下检测验证」），表内不复述。
- 「时空分布」不适用本条的唯一情形：项目**无表4.1-1**（识别仅以段落表述）时，才需要在引言里用一句话交代分布，但仍应写「与评价单元／作业时段相对应」，不写「在空间上…在时间上…」。
