# 删段落会连带删掉它承载的分节符——改字不删段，并给生成器加存活闸门

> 一条判例只讲一件事。写不成一句话的，拆成两条。

## 触发场景

DOCX 的分节符（`w:sectPr`）不是独立元素，它挂在**某个段落的 `w:pPr` 里**。
所以「删掉一个没用的段落」可能同时删掉一处页码、纸向、页眉页脚的切换点。
用生成器批量改稿时，这类删除动作写在脚本里，肉眼看不见。

## 做法

**错误做法**：为把第 3.4 的第4条并入「存在的主要问题」，用 `remove(698)` 整段删除源稿收尾段。
该段 pPr 里带着 `sectPr`（正文纵向 → 表4.3-1 起横向的分界）。

后果与症状：

| 指标 | 基线 | 出错稿 |
|---|---|---|
| 总页数 | 75 | 87 |
| 横排页 | 14 页（第 42 页起，间断） | 第 **7—42** 页连续横排 |
| 第2章起页 | 19 | 21（**改动点之前**就涨了） |
| 第3章起页 | 35 | 46 |

**症状的误导性**：页数在改动点之前就膨胀，而内容一处没多加（对照脚本比对 body 元素，
差异只有第3章那几十个元素）。极易误判成「插了三张表把排版撑爆」，然后去调列宽、压字号——
方向全错，越改越远。

**正确做法**：

1. **改字不删段**：用 `replace(i, 新文字)` 只换内容，`pPr`（含 `sectPr`）原样保留。
2. **先 dump 再动手**：列出源稿中所有携带 `sectPr` 的段落下标，与所有 `remove()` 目标逐个比对。
3. **加硬闸门**（本轮已落入生成器）：

   ```python
   # 序列化前：携带 sectPr 的原稿段落一个都不能丢
   _lost=[i for i,p in enumerate(ps)
          if not (ps.index(ch6_head)<=i<ps.index(ch7_head))
          and p.find(W+'pPr/'+W+'sectPr') is not None and p.getparent() is None]
   if _lost: raise RuntimeError('分节符段落被删除，版式将错乱：ps=%s'%_lost)
   _nsec=len(doc.xpath('//w:body/w:p/w:pPr/w:sectPr',namespaces=NS))+len(doc.xpath('//w:body/w:sectPr',namespaces=NS))
   if _nsec<14: raise RuntimeError('分节符数量异常：%d'%_nsec)
   ```

4. **先看方向、再看内容**：

   ```python
   ''.join('L' if p.rect.width>p.rect.height else 'P' for p in doc)
   ```

   把整本横纵序列与基线逐位比对。序列错位＝节属性问题；序列一致、页数仍差＝内容问题。

## 依据

- 项目：`build_review.py` 原 `remove(698,'第3章3.4：原第4条并入「存在的主要问题」第三条')`
- 项目：源稿 `mago_original.docx` body 下标 339 携带 portrait `sectPr`，其 ps 下标为 698
- 项目：对照实验 `_ab_ch3.py`（只把第3章 4 处 `after()` 置空）仍为 87 页 ⇒ 与新增表格无关
- 判例：`PL-GEN-0019`（加横向页前先 dump 全部 sectPr）为同族结构判据

## 可复用规则

> 删段落前先查该段是否承载 `sectPr`；承载者只能改文字、不能删段。生成器必须内置
> 分节符「存活 + 数量」两重断言。页数异常时先打整本横纵序列与基线比对，再谈内容。

## 反例或例外

- **整章替换**（本报告第6章：整章删除后重建）会连带废弃该区间的分节符，属有意为之，
  闸门必须显式豁免那段 `ch6_head`—`ch7_head` 区间，否则天天误报。
- **新增**分节符（造横向节）是允许的；闸门只查「原稿已有的是否丢失」，不禁止新增。
- 确需删除承载分节符的段落时，先把 `sectPr` `deepcopy` 挂到相邻保留段或新建段上。

## 补案（2026-10-05 云端）：整章重写时的锚段保留与删除闸门

第5章（10-04）、第7章（10-05）整章改由数据文件生成，原稿该章段落要整段删除。做法：
- **保留两类锚段**：章标题段（第7章 ps[965]——第6章整章替换按其文字定位，文字不得改）与**分节符段**（第5章 ps[907]、
  第7章 ps[999]）。新内容插在两者之间，分节符段由此成为章末分节符段。
- **删除区间可以跨过分节符段分两截删**（第7章：965→999、999→1003 各删一截），**删除循环遇到带 sectPr 的段即抛错**，
  不靠事后数分节符总数兜底。
- 删掉的原段落在 `reviewed[]` 里登记「整章重写，原段落删除」，避免覆盖率统计把它们算成漏审。
