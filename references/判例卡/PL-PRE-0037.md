# 职业病危害因素名称对应分类目录，目录外的（油雾、煤油等）不列为因素

> 一条判例只讲一件事。写不成一句话的，拆成两条。

## 触发场景

冷轧项目初稿把油雾、煤油和 10/17 kHz 感应加热交变磁场当作职业病危害因素，一路写进限值、防护设施、关键控制点、体检和费用；
名称又混用 GBZ 2.1 条目名和类比报告原记名称。用户问「油雾不算职业病危害因素吧？」——分类目录没有油雾，也没有矿物油、润滑油、切削液、煤油，
GBZ 2.1—2019 也无油雾限值。

## 错误做法

- 按物料或现象起名（油雾、酸雾、煤油、感应加热电磁场、视屏作业）并当作因素计数。
- 同一因素全文多名：氯化氢／氯化氢及盐酸、氮氧化物／氮氧化合物、工频电场／工频电磁场。
- 只看商品名不比 CAS 号，漏识别目录内成分。

## 正确做法

常见名称对照（左为不规范写法，右为目录名）：

| 不规范写法 | 分类目录名称 | 限值引用 |
|---|---|---|
| 氯化氢、盐酸、酸雾 | 氯化氢及盐酸 | GBZ 2.1 氯化氢及盐酸 MAC 7.5 |
| 氯 | 氯气 | GBZ 2.1 氯 MAC 1 |
| 氮氧化物、一氧化氮、二氧化氮 | 氮氧化合物 | GBZ 2.1 氮氧化物（一氧化氮和二氧化氮）PC-TWA 5、PC-STEL 10（2019 版已无「以 NO₂ 计」和一氧化氮单列限值） |
| 锰及其无机化合物 | 锰及其化合物 | GBZ 2.1 锰及其无机化合物（按 MnO₂ 计）0.15 |
| 工频电场 | 工频电磁场 | GBZ 2.2 工频电场 5 kV/m |
| 激光辐射 | 激光 | GBZ 2.2 激光辐射 |
| 氧化铁粉尘、其他粉尘（氧化铁皮） | 铁及其化合物粉尘 | GBZ 2.1 无该条，按其他粉尘 PC-TWA 8（总尘） |
| 磨削粉尘、磨辊粉尘 | 砂轮磨尘 | GBZ 2.1 砂轮磨尘 |

- 病名按《职业病分类和目录》现行版写（噪声聋、锰及其化合物中毒、金属及其化合物粉尘肺沉着病、电焊工尘肺等）。
- 目录外的写一句「不属于目录所列职业病危害因素」并保留必要的一般防护建议，不进计数、限值、关键控制点和体检。
- 删因素、改名后，图例编号、表格序号引用、小结计数和第8～11章一次改齐。

## 可复用规则

职业病危害因素只认分类目录：目录名、CAS 比对、目录外不列；全文、图、表同名同数。
