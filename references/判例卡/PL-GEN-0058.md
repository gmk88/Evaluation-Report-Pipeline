# 报告写给专家和企业看：删解释性语言，资料缺口按缺的是谁写

> 一条判例只讲一件事。写不成一句话的，拆成两条。

## 触发场景

方法改对了、事实都有出处的稿子，用户仍说“写的太深了”“不要那么多解释性语言”。问题不在事实，而在每处缺口都解释一遍、每个取值都说明为什么，读者找不到结论。

## 错误做法

| 类型 | 改前 |
|---|---|
| 资料边界说明 | “用地历史、土壤状况和与厂区污水处理站的距离，可研未写，现场调查时向建设单位核实；” |
| 检索计数当免责 | “急救用品、喷淋洗眼、泄险区和风向标可研未写（可研全文“洗眼”“喷淋”“泄险”“风向标”均0处）” |
| 正文点名条号 | “按 GBZ/T 196—2025 第10.2.3.1条f）款，依托……见表2.1-3” |
| 方法取舍理由 | 表3.1-1“不采用其他方法的理由”列；表注解释日口径、周口径和 ER 不取整 |
| 自造计算层 | “控制优先级一级～三级”；“防护用品按原值计”第三种状态；与半定量对不上的定性评估 |

## 正确做法

| 类型 | 改后 |
|---|---|
| 资料边界说明 | 整句删（这类资料不收集，`PL-PRE-0045`） |
| 检索计数当免责 | “可研没有急救用品、喷淋洗眼、泄险区和风向标。” |
| 正文点名条号 | “依托、利旧和共用的设施见表2.1-3。” |
| 方法取舍理由 | 只写用了什么方法、结果是什么 |
| 自造计算层 | 删；控制对策照抄 GBZ/T 298—2017 表J.2 |

晋钢烧结的结果：全文【待核】156→0、“现场调查时”91→0、“可研未写”62→0，判定格、表行和行序一个未变；第3章字数为原稿的80%，危害、接触指数、风险等级和对策的数据都在；第11章新增表11.2-1 待补资料清单13行。

## 可复用规则

报告写给评审专家和建设单位看：判据是“删掉这句，评价对象或结论有没有损失”；不写编者口吻、资料边界说明、方法取舍理由、正文条号和自造计算层；资料缺口按缺的是谁写（可研没写的写成“可研没有……”并提补充措施，等建设单位、设计单位提供或确认的全清），不列待补资料清单（PL-GEN-0060）。
