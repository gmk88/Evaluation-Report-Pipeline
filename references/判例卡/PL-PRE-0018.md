# 先判因素是否适用（毒物／单纯窒息性气体），再判方法档位；不编造数值风险指数

> **2026-10-04独立核验补充优先口径**：用户明确不适用或可靠对应不了的EI因素可以不纳入，n随实际纳入项变化。下文更早的“8项均算、控制均取1”仅为旧稿历史，不能作为强制取值规则。EI1是最有利控制状态，不是保守假设；适用但缺资料的控制项须保留待核，不能默认充分或删除后宣称风险低。

## 触发场景

马沟的主要危害是甲烷、噪声、低温，重点岗位是卸车接管、加气、巡检、检维修和异常处置。其中异常情景的定量参数（泄漏浓度、氧含量、持续时间）手头都没有——**但「没有浓度」并不等于「不能做风险评估」**，要先看导则有没有给出不需要浓度的算法。

## 做法

**错误做法**：①编造异常泄漏浓度、氧含量和持续时间，据此给出数值风险指数或定量等级；②**把「无检测结果」直接当成「不能做风险评估」**，一律退回定性，并把"不计算 HR、ER、R"写进报告——导则的接触指数法本来就不需要浓度。

**正确做法（先判档位，再决定算什么）**：

| 手上有什么 | 用哪个方法（GBZ/T 298—2017） | 能不能算 |
|---|---|---|
| 有检测结果 ＋ 有 OEL | 接触比值法（F.3.1）／综合指数法（F.3.3，需 E/OEL） | 能 |
| **无检测结果 或 无 OEL** | **接触指数法（F.3.2、表F.4）** | **能**（输入是蒸气压／粒径、控制措施、使用量、接触时间） |
| 有接触浓度 ＋ RfC／IUR 等剂量-反应参数 | 定量法（附录G） | 输入不足时不做 |

算出 **HR、ER、R＝√(HR×ER)（四舍五入取整）与表F.6 风险等级**，并写明控制措施类接触指数的取值前提；只有确实不能算的（需要浓度的定量法），才写情景加定性分析，并把缺失输入列为待核。

- **2026-10-04 补案**：马沟 4.3.2 原稿写「资料不满足 GBZ/T 298 接触指数法或接触比值法的可靠计算条件，不计算 HR、ER、R 或 HQ」。用户批注「这一章按照风险评估技术规范编写」。取得 GBZ/T 298—2017 正式原文后按表F.4 赋 8 项接触指数（蒸气压5、工程防护1、应急救援设施1、职业病防护用品1、应急救援措施1、职业卫生管理1、周使用量5、周接触时间5），式（F.5）ER＝(∏EI)^(1/8)＝1.8；表F.1／F.2 取高得 HR＝2；式（F.6）R＝√(2×1.8)＝1.9，四舍五入取整 2，表F.6 判为**低风险**。方法档位改后同步改了 §1.6 方法章与表1.6-1，三处口径一致。

## 可复用规则

> 定量风险分析只在有可靠输入参数时做，不用估计值凑数字；**但「无检测结果」≠「不能做风险评估」——
> 导则的接触指数法不需要浓度，属于可算档位，必须算下来并给出 HR、ER、R 与风险等级**。
> 判据：先问「这个方法的输入项我有没有」，而不是先问「我有没有浓度」。

## 反例或例外

有可靠泄漏模型和经确认的参数时可以定量，须写明模型与参数来源。

另三点例外／边界：

- 接触指数法里的「蒸气压／空气动力学直径」栏，导则只给了固（空气动力学直径）与液（蒸气压）两套口径：**对常温常压气体按最高档（＞13300 Pa）取值，并在报告中写明该取值口径**，不留暗规则。
- 控制措施类接触指数（工程防护、应急救援设施、职业病防护用品、应急救援措施、职业卫生管理）在预评价阶段均为「拟采取」，按充分计属有据的保守度假设，但**必须在文内点明「按可研拟采取措施且充分计、运行后复核」**，否则等于把拟采取写成已落实。
- 改方法档位必须**同时**改方法章（§1.6）与方法表（表1.6-1）——只改正文会留下「方法章说定性、正文算半定量」的矛盾。

## 2026-10-04 回退更正：甲烷非毒物，整套毒物模型都不适用

**触发**：用户质疑「甲烷非毒物，是否不适用风险评估呢？」

**核验**（均读正式原文）：
- **GBZ/T 298—2017 §1 范围**：适用于"因接触**化学有害因素**所导致的职业健康风险"；其 §6.2.5 给出四条危害特征分级路径（R-phrases／**依据 GBZ 230（毒物）**／ACGIH-IARC **致癌性**／EPA RfC-IUR），**全部以"毒性"为轴**；附录F 表F.1／F.2 亦按毒性分类与 LD50／LC50 划分。
- **GBZ/T 230—2025** 只管"**毒物**危害程度"。
- **GBZ/T 196—2025 §8.4 原文**：依据 **GBZ 230 和 GBZ/T 298 等国内外相关标准**（"等"字留了余地）。

**结论**：甲烷（ACGIH 归 **Simple asphyxiant**，本质危害是**置换氧**）——① **GBZ/T 230 不适用**（非毒物）；② **GBZ/T 298 的"危害特征评估"环节不适用**（该模型没有"窒息性"这一维度，硬套只会输出最低档）；③ 接触指数法的"蒸气压"栏也是为挥发性液体／粉尘设计，气体套用牵强。硬算得到的 **HR＝2、ER＝1.8、R＝2"低风险"，把可致死的急性缺氧窒息评成低风险**，是误导。

**回退做法**：保留 GBZ/T 298 的**四要素框架**（危害识别／危害特征评估／接触评估／风险特征描述），**危害特征按"窒息性"写**（ACGIH 单纯窒息性气体、~~NIOSH REL 1000 ppm~~（查无出处，2026-10-05 已删，见文末补注）、最低氧含量），**接触按作业情景**（露天／受限空间、装卸／检维修、能否积聚），**风险按情景定性**（正常工况可控；异常泄漏与受限空间作业属可致急性缺氧窒息的高风险情景），**不计算 HR／ER／R**；依据改引 **GBZ/T 205—2007《密闭空间作业职业危害防护规范》**（落实 §8.4"等国内外相关标准"）。表4.3-2 列头同步由「分析内容／风险特征及控制要求」改为「评价内容／**评价结论**」，**本节不再写控制要求**（控制要求归第 9、10 章）。

**联动**：同时改 §1.6 方法章、表1.6-1「职业病危害风险评估法」行；并订正本卡上一版补案中"无检测结果也应算下来"的说法——**该说法仅对毒物类因素成立**，对单纯窒息性气体应先排除适用性。

**可复用规则（新增）**：**先问"这个因素适不适用这套模型"，再问"这个方法我有没有输入"**。以毒性为轴的危害分级模型（GBZ/T 230、GBZ/T 298 危害特征分级）对**单纯窒息性气体**与**物理因素**结构性不适用；此时应声明不适用、改用对口标准（缺氧／受限空间 → GBZ/T 205；噪声 → GBZ/T 229 系列），而不是硬凑一个数值。

> ⚠ **本节「依据改引 GBZ/T 205—2007（落实 §8.4『等国内外相关标准』）」的说法已于 2026-10-04 被用户否定并推翻**，见下节。

本卡上一节给出的解释（GBZ/T 205—2007 可凭 §8.4 的「等」字充当定性评估路径）被用户直接否定：
「**你瞎说，205怎么能算风险评估法？对标准一点敬畏都没有吗**」。

**错在哪**（这是本卡最该记住的一条）：

- **GBZ/T 277—2016 附录 A.5** 给出了风险评估法的实质：**利用接触水平与相关接触限值标准的对比**评估危害程度与分级。
  甲烷在 GBZ 2.1—2019 里**没有职业接触限值** → 对比的另一端不存在 → **该方法在甲烷上根本不成立**，
  不是「换个标准来做」的问题。
- **§8.4 里的「等国内外相关标准」指引的是同类方法类标准**，不是「随便找一本相关标准来充当方法」；
- **GBZ/T 205—2007 是作业条件与防护类规范**（受限空间作业条件、氧含量检测、通风、监护、个体防护与应急救援），
  **通篇没有危害程度评估方法**，当不了方法依据。它的正确落点是**第6章防护与应急救援**。

**改法（三处一起正名）**：

| # | 位置 | 改前 | 改后 |
|---|---|---|---|
| ① | 节名 | 4.3.2 职业病危害风险评估 | **4.3.2 甲烷缺氧窒息情景分析** |
| ② | 表题／列头／行名 | 表4.3-2 甲烷职业健康风险评估；评估环节／评价内容／评价结论；危害特征评估／接触评估／风险特征描述 | **表4.3-2 甲烷缺氧窒息情景与结论**；**分析环节／分析内容／分析结论**；危害特征／接触情形／**风险结论** |
| ③ | 方法章与方法表 | §1.6.4 职业病危害风险评估法（整节）＋表1.6-1「职业病危害风险评估法」行＋前言方法清单 | **整节删除、该行删除、清单去掉**；原 §1.6.5 顺次改为 §1.6.4，不留编号空档 |

替代做法的**方法依据**改引 **GBZ/T 196—2025 §10.2.5.3 末句**（对没有检测数据资料的因素，可根据定性定量分析方法
推测预期接触水平及对劳动者健康的影响）；受限空间作业条件另按 GBZ/T 205—2007 评价，只在第6章落地。

**教训**：**判定结论一变，名字、依据、方法章要跟着一起变**。只改正文不改名 = 名不符实；
拿非方法类标准顶替方法依据 = 对标准性质的越界解释。命名与依据侧的规则见 [[PL-GEN-0037]]。

## 2026-10-04 补案：指向句必须双向闭环，先核实落点在不在再动手

**触发**：4.3.2 引言写「受限空间作业条件按 GBZ/T 205—2007 评价，其检测报警、防护与应急救援要求见第6章」，
我在收尾时把它记成待办「第6章未引用 GBZ/T 205」。用户选「补引（闭环）」后先做核查，**发现前提是错的**：

| 查什么 | 实测 |
|---|---|
| 6.3 依据清单 | **已列**「GBZ/T 205《密闭空间作业职业危害防护规范》」 |
| 表6.3-1 | **已有 4 个 205 检查项**：测氧含量 6.1.2.1、空气呼吸器 6.1.4、受限空间作业管理 4.1.1、预案演练 12.1 |
| §1.2.2 依据清单 | **第 24 条**＝《密闭空间作业职业危害防护规范》（GBZ/T 205—2007） |
| 6.1 引言 | 只提 GBZ/T 196—2025 §10.2.7，**没有正面说「受限空间作业条件按 205 评价」** |

即落点**本来就在**，缺的是第6章**没有一句正面回指**——指针是**单向**的（4.3.2→第6章，第6章无对应依据句）。
改法＝在 6.1 引言同一句内续写「…；其中受限空间（储罐内部、地下管沟等）作业的作业条件与防护要求，
按《密闭空间作业职业危害防护规范》（GBZ/T 205—2007）评价，检测、个体防护和应急救援的具体要求见表6.3-1。」

**两条教训**：

1. **写「见第 N 章」之前，先确认第 N 章有能被检索到的对应依据句**。指向句的单向是隐性缺口：
   读者顺着指针翻过去找不到「为什么按这本标准」，而全文检索「205」却到处都是——落点在，回应缺。
   补齐不等于搬一份落点清单过去，只需一句正面依据陈述。
2. **报待办前先核实，别把自己没查完就下的印象写成事实**。本条待办原话「第6章只以 GBZ/T 223 等作依据」
   经不起一次检索。**「我记着好像没有」不是发现**；坐标（章／节／条号）必须现场查过。
