# 行业资料：钢铁企业烧结烟气协同治理（循环流化床协同处置工业固废）

> 整理自晋钢智造烧结烟气协同处置工业固废综合利用项目预评价（AT-2026-Y015，2026-10，风险评估法）。做“烧结烟气作一次、二次风＋循环流化床烧含碳固废＋产汽供热或发电”一类项目时参考。
> 只学识别思路、方法要点和易错点；**本项目的规模、参数、定员、平面位置一律以本项目可研、初设为准**，不搬晋钢的数。

## 一、工艺路线先认清，资料先认准

- 烧结主抽风机后的烧结烟气（含一氧化碳、二氧化硫、氮氧化物、粉尘）经增压风机作循环流化床的一次风、二次风；炉内燃烧煤矸石、煤泥、冶金除尘灰等含碳固废，可掺烧高炉煤气；炉内喷石灰石粉脱硫，SNCR 喷氨水脱硝；余热产汽供热或发电。配套料场、筛分破碎、输料、料仓、除灰、除渣、加药取样、电气和热控。
- **同一集团常有几个相近项目**（晋钢：330 t/h 供热技改、730 t/h＋250 MW 发电、200 MW 煤气发电），名称只差几个字。开工先核：备案证的项目名称、代码、规模和投资，可研题名和规模，初设封面案卷号和正文第1节。三者对不上的不用，写进交稿说明（晋钢项目文件夹里放的初设属于另一个项目）。
- 技改项目：第2章章名为“现有企业概况及建设项目工程分析”；利旧、依托、共用设施（化验室、共用氨水站、钢厂集控中心、浴室等）在评价范围内（GBZ/T 196—2025 第6.1条），不得以“利旧”为由不评。

## 二、因素识别与名称（按《职业病危害因素分类目录》和 GBZ 2.1，`PL-PRE-0037`）

| 环节 | 因素 | 说明 |
|---|---|---|
| 料场、碎料、输料、料仓 | 矽尘、噪声 | 燃料游离SiO₂未检测前按矽尘评价，表注写“最终以投产前游离SiO₂检测结果确定”；＜10%时按煤尘或其他粉尘重判。可研的“SiO₂ 55%”是全硅，不能当游离SiO₂ |
| 装置本体、烟风道、除尘器及引风机 | 一氧化碳、二氧化硫、氮氧化合物、矽尘（灰渣）、高温、噪声 | 正压段（增压风机后）和看火孔、人孔是主要逸散点；烧结烟气可研写“硫化氢、羰基硫无”的不识别 |
| 高炉煤气接入、点火 | 一氧化碳 | 点火燃料资料常前后矛盾（高炉煤气或液化石油气），在第2章资料口径差异写一次 |
| 石灰石粉仓 | 石灰石粉尘、噪声 | 罐车气力卸料对接口 |
| 氨水站、SNCR计量喷射区 | 氨 | 氨水站常与已有机组共用：写清归属，现状资料没有的按可研写 |
| 灰库、渣仓、冷渣机 | 矽尘（或其他粉尘）、高温、噪声 | 装车点常由社会运力司机操作，写清由谁监护 |
| 加药间 | 其他粉尘（粉状磷酸三钠人工投加时）、肼（加联氨时） | 不设除盐水处理的，不识别盐酸、氢氧化钠 |
| 配电室、变频器室 | 工频电磁场、噪声 | 预期远低于限值 |
| 料仓、炉膛、烟道等密闭空间 | 甲烷积聚、缺氧（情景分析） | 甲烷是单纯窒息性气体，不算风险等级、不计因素个数 |
| 检修 | 电焊烟尘、锰及其化合物、臭氧、紫外线、砂轮磨尘、手传振动 | 可研没写检修内容的，按劳动过程推断识别；可研没有写是否动火、打磨的，写“可研没有写日常检修是否动火、打磨，未作风险评估”，表9.1-2写一句 |

## 三、风险评估要点（GBZ/T 298—2017 半定量，第3章）

- 一氧化碳是气体，接触指数里的“蒸气压”取5（送审稿取1是错的）。生产过程逸散的毒物和粉尘，“使用量”按逸散源所在系统的处理量取，表注写一次取值口径。
- 控制措施、个人防护、管理的 EI 按可研方案的实际状态取值。可研阶段这几项多为4～5，所以“可研方案状态”下大多数组合是高风险；落实补充措施后降为中等、低风险。这是方法使然，要在3.5和第11章把两种状态都写出来，不能只写一种。
- 四班三运转：周接触时间＝每班接触时间×5.25。巡检时间可用可研“现场巡视时间不超过2小时”作上限估算，分配到各条巡检路线。
- 噪声、高温、工频电场不用 GBZ/T 298：按 GBZ 2.2—2007 推算预期接触水平；可研没有声源数据的，写满足限值的条件（各岗位工作地点声级上限）。不用“后果严重性×发生可能性”矩阵（无标准出处）。

## 四、高毒物品与检测频次

- 氨、一氧化碳、二氧化氮、肼、锰化合物列入《高毒物品目录》（卫法监发〔2003〕142号），二氧化硫不在目录内（晋钢项目按转录本核，交稿前回官方原文核）。
- 由此带来：高毒物品告知卡；《使用有毒物品作业场所劳动保护条例》第二十六条：存在高毒作业的场所每月至少检测一次，每半年至少进行一次职业中毒危害控制效果评价；第十二条：设红色区域警示线和通讯报警设备；第二十七条：工作服清洗、存放专用间。

## 五、风险类别（第11章）

- 以含碳固废为燃料在循环流化床中燃烧产汽供热：《建设项目职业病危害风险分类管理目录（2021年版）》D443.1“热力生产和供应（燃煤、核能）”，严重。按所属烧结工序归 C311 炼铁也是严重。归“D443 一般”要有燃料不属燃煤的依据。
- 风险类别是行业分类，与第3章的风险等级是两回事，不互相代替。

## 六、晋钢烧结送审稿出过的错（已写进项目 `检查规则.md` 的“禁用”）

- 大段套用另一个项目（金秋铸造高炉尾气项目）的报告，连带搬来对方的事实：安环部、4名专职管理人员、12项制度、已申报、已取得证书、智能管控平台、10.5 kV、各机组支管、盐渣、热泵、余热供暖等。各章重合率64%～90%。
- 把可研没有的设施写成“可研已有”：固定式一氧化碳报警、喷淋洗眼器、空气呼吸器、事故通风联锁、氮气置换、紧急切断；全书90项检查只有“符合”“基本符合”。
- 风险评估：定性和半定量结果“取高”、控制措施 EI 取最有利值、一氧化碳蒸气压 EI 取1、ER 先取整再算 R；物理因素用无出处的“罗马尼亚模型”矩阵；化验室以“利旧”为由不评。
- 依据：GB/T 18664—2002、GB/T 23466—2009 已被2025版代替；“GB 38900.1”不存在；令号写成“〔年〕N号”。
