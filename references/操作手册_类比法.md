## 1 什么时候用

- 新建、改建、扩建项目可研阶段的职业病危害预评价；已建成项目补做“三同时”的预评价（马沟即此情形）。
- 起草、修改、审阅预评价报告任一章；把已有的 Word 成稿转成可自动出稿的项目（`import`）。
- 核对预评价与设计专篇、控评之间的事实和引用。
- 不用于：设计专篇、控评（各有 skill）、用人单位现状评价（WS/T 751—2015）、放射性职业病危害评价（另按 GBZ/T 181—2021 编制，`PL-PRE-0044`）。

## 2 总规矩（先读）

1. **报告是生成物**：只改项目文件夹里的文字文件（`项目信息.md`、`正文/*.md`），再 `build`；不直接改输出的 Word，否则下次生成会被覆盖（`PL-GEN-0008`）。
2. **事实只来自本项目资料**（委托书、立项文件、可研、图纸、检测和体检报告、建设单位确认）。缺的写【待核】或【待填】（校验报告自动列进“待办”），不臆造（`PL-GEN-0002`、`PL-GEN-0050`）；交稿前全部清掉：补得到的补上，补不到的按第12条写，报告不列待补资料清单（`PL-GEN-0058`、`PL-GEN-0060`）。骨架和范例只给格式，不给事实（`PL-PRE-0008`）。资料之间说法不一时，按更具体、更新的资料定口径（初设优于可研，设备表、布置图优于概述文字），在第2章写一次、全文统一（`PL-PRE-0040`）。
3. **每章动笔前走五步**：①四类依据一次取齐（第5节）→②定位本阶段要求→③认清判定依据（阶段主文件＋通用标准＋专项标准＋项目事实）→④列“必答问题清单”（每条带依据、要回答什么、证据从哪来）→⑤出任务计划。计划没出不动笔（`PL-GEN-0022`、`PL-GEN-0029`）。
4. **改动范围＝解决问题必须做的**：同一口径全文改全，不借机改无关章节（`PL-PRE-0010`）；审阅或提建议前先对照已定口径，不把已定的事再翻出来（`PL-GEN-0042`）。
5. **只评价职业病危害因素**：防静电、防寒保暖等安全或舒适性内容不评价；放射性（电离辐射）因素另做放射性评价，本报告不评价（`PL-PRE-0044`）；密闭（受限）空间只关注有人进入的（`PL-GEN-0040`）。不写成论文。
6. **中间成果随做随存**（Notion、会话文件），电脑会回档（`PL-GEN-0045`）。**每轮动手前先防回档**：上传上轮交付的 Word，与本次 `build` 出的 Word 跑 `compare`，应显示“正文一致”；对不上就是回档，先按会话记录逐轮补回再改（`PL-GEN-0056`）。
7. **专业判断自己做**：标准怎么要求、按什么危险源配置、资料取哪份、名称怎么统一、判什么档，评价组自己定、直接改。给用户的说明用简单的话写改了哪里、依据是什么；建设单位才能提供的事实（倒班方式、每班人数、房间设置、设备选型等），报告里按可研和不利情况写，直接影响危害识别的少数几项写进交稿说明，不进报告（`PL-GEN-0060`）；不写“需要你确认”“告诉我就改”（`PL-GEN-0055`）。
8. **改写用户原稿时纠错不删减**：原稿每节、每表、每个检查条款都要有去向（保留、改写、合并、移章，或删除并写理由）；能删的只有不实、跨项目残留、已废止依据、重复抄写四类。事实错改事实，口吻错改口吻，照抄条文的检查表条款全留、只压缩表述。每章写完跑 `coverage`，去重后字数不低于原稿的80%（`PL-PRE-0042`，做法见 `references/篇幅与覆盖核对.md`）。
9. **写给专家和企业看**（`PL-GEN-0058`）：判据是“删掉这句，评价对象或结论有没有损失”。不写编者口吻（本节只写、以下不再、本表只作对照）、资料边界说明（可研未写、评价组估、暂按、现场调查时核实）、方法取舍理由和推导细节、正文点名条号（检查表“依据”栏和1.2 照写）、自造计算层。“可研没有××”是评价发现，保留；估算口径在首次出现处写一次；判定因可研缺资料而定的，分析栏写明可研没有什么，并提补充措施（第12条）。
10. **资料只收集到能下结论为止**（`PL-GEN-0060`）：会改变危害因素、接触人员、接触时间或防护设施判定的才收集；设备参数、建筑面积、储罐容积、作业频次、统计站点和年份等细节，以及用地历史、土壤状况、厂区权属、环评卫生防护距离等与职业卫生不直接相关的内容不收集。报告不列待补资料清单，也不设“需补充的资料”列；资料缺口按第12条写；确需建设单位提供的少数几项写在交稿说明里。
11. **选址边界**（`PL-PRE-0045`，只用于编写，不写进报告）：自然疫源地、地方病区网上简单查一下，写一句结论（如“建设项目所在地不属于自然疫源地、地方病区”），不写出处和检索过程；能备案的建设项目一般不在自然疫源地上。不在其中的，选址只分析与周边企业、设施的交叉污染和联合作用（GBZ/T 196—2025 第10.2.3.2条c）、d），GBZ 1—2010 第5.1.5条）；被保护对象上风侧和卫生防护距离（GBZ 1—2010 第5.1.4条）属环境评价的选址要求，不评价、不写。确在自然疫源地、地方病区的，按第10.2.3.2条b）和第10.2.5.2条写。
12. **资料缺口看缺的是谁**（`PL-GEN-0060` 第6、7条，用户 10-31 02:09 纠正）：可研没写的，评价部分写清楚（“可研没有写／没有明确／没有给出……”，前后不一的写“可研××写法不一”），再提补充措施，不清；等建设单位、设计单位提供或确认的（待核、待补充、由××确认、确认后、待取得、资料不足），全清，能落到设计阶段或投产前的写成那时要做的事。不按影响不影响判定来分。正文不写“未定”“可研未给出”（骨架检查规则禁用）。

## 3 三步出报告

```bash
cd occupational-hazard-pre-assessment
# ① 建项目：复制骨架（项目信息、检查规则、正文 11 章、资料、图）
python3 scripts/report.py new 某项目 --名称 "某某项目"
#    填 某项目/项目信息.md；按章写 某项目/正文/01～11（每章已有写法提示和评价表表头）
# ② 生成：检查 → Word → PDF → 回填目录页码和“共N页” → 复核
python3 scripts/report.py build 某项目
# ③ 看 某项目/输出/校验报告.md：错误全改、提示逐条确认、待办列给用户；改完再 build
```

| 命令 | 作用 |
|---|---|
| `new 文件夹 --名称 项目名称` | 新建项目 |
| `import 成稿.docx 文件夹` | 把已有 Word 成稿转成项目文件夹（同类项目当样板改，或核对旧稿）；马沟已转好，在 `examples/马沟/` |
| `check 文件夹` | 只检查，不出稿 |
| `build 文件夹 [--不出PDF]` | 出稿（只要 Word 时加 `--不出PDF`） |
| `compare 旧稿.docx 新稿.docx` | 两份 Word 正文逐段比对，按章列出不同之处；一致时显示“正文一致”。每轮开工前用它核对电脑上的稿子是不是上轮交付的版本 |
| `coverage 原稿项目 新项目 [--下限 0.8]` | 改写用户原稿时逐章比对去重后字数、表格数、表行数；字数低于下限报错，表格减少只提示；结果在 `新项目/输出/篇幅核对.md`。原稿 Word 先用 `import` 转成项目文件夹 |
| `wps 文件夹 [--发布]` | `build --不出PDF` 之后用 WPS 命令行出 PDF：两轮导出、回填目录页码和“共N页”、逐页核对、查字体和插图；结果放 `文件夹/WPS核对/时间戳/`，加 `--发布` 才放进 `输出/`（`PL-GEN-0059`） |
| `finalize 文件夹 [--核对]` | PDF 由 Word 导出时用：按 `输出/` 里同名 PDF 回填目录页码和“共N页”；重新导出后加 `--核对` 逐页核对（PDF 比 Word 旧会报错；PDF 目录上印的页码也核） |
| `test [--快速]` | 自测（`--快速` 不渲染 PDF） |

输出在项目的 `输出/` 里：`项目名称职业病危害预评价报告_报告编号.docx`、同名 `.pdf`、`校验报告.md`。

**用 WPS 出 PDF**（macOS 装了 WPS 时用；不占 Microsoft Word，几个窗口同时出稿不抢；`PL-GEN-0059`）

```bash
python3 scripts/report.py build 某项目 --不出PDF
python3 scripts/report.py wps 某项目             # 只核对：结果在 某项目/WPS核对/时间戳/，不动 输出/
python3 scripts/report.py wps 某项目 --发布      # 核对通过后把 Word（目录页码已回填）和 PDF 放进 输出/，原来的存到核对文件夹
```

- WPS 命令行不按字体名找本机字体，只用嵌在 DOCX 里的：程序每轮另存一份渲染副本，嵌入裁剪后的仿宋（FangSongCN）、宋体（SimSunCN）、Times New Roman 常规和粗体再导出。交付的 DOCX 不嵌字体。字体文件在 `~/Library/Fonts` 和系统 Supplemental 文件夹，缺了会报错停下，不会出苹方稿。
- 导出两轮：WPS 命令行导出时不更新目录域，印的是 DOCX 里存的页码，所以第一轮按 PDF 回填目录页码，第二轮用回填后的 Word 重新导出、逐页核对。PDF 要有仿宋、宋体，正文不能有苹方，插图张数要与 Word 相同，否则报错不交付。
- 源文件比 `输出/` 里的 Word 新、或标题对不上时不导出，先重新 build。核对文件夹不要放 `/tmp`，WPS 命令行读不了那里。
- WPS 命令行要登录 WPS 会员账号（退出码 100、101）；它装在 `/Applications/wpsoffice.app/Contents/MacOS/wpscli`，装在别处的设环境变量 `PE_WPSCLI`。
- 实测：晋钢烧结 294 页约 18 秒；马沟范例 119 页约 14 秒，目录 101 条、页脚逐页核对通过，用字与 Word 版相同。

**用 Word 出 PDF**（电脑上不能用 LibreOffice 时，macOS；`PL-GEN-0057`）

```bash
python3 scripts/report.py build 某项目 --不出PDF
osascript scripts/Word关闭窗口.applescript "报告编号"   # 关掉同名 docx 的旧窗口；别的文档窗口不动，出现存储提示时不替用户选
open -a "Microsoft Word" 某项目/输出/某报告.docx         # 等约 25 秒加载完
osascript scripts/Word打印PDF.applescript "报告编号"   # 打印对话框“存储为PDF”
# PDF 存在存储面板上次用过的文件夹：找到后移到 某项目/输出/，与 docx 同名；按文件是否生成判断成败，不看脚本返回值
python3 scripts/report.py finalize 某项目              # 回填目录页码和“共N页”（docx 变了）
# 再关窗口、重开、导出一次，然后：
python3 scripts/report.py finalize 某项目 --核对       # 错误为 0 才交付
```

Word 未激活时“另存为 PDF”不可用（AppleScript 报 -1708），所以走打印对话框。回填后不关旧窗口就打印，Word 会印出内存里的旧稿（目录页码全为 0）。

目录是 Word 目录域（2026-10-30 起）：Word 打印时自己更新页码，第一次导出的 PDF 目录就是真实页码；`finalize` 照常回填、核对。PDF 会存到 Word 打印面板上次用过的文件夹，可能是交付文件夹，找到后马上移走。

**程序自动做的事**

- **版式**：程序自动排版以下各项，版式取自马沟最终版：
  - 封面、声明、人员表；
  - 目录：Word 目录域（标题带书签、页码是 PAGEREF 域），Word 导出 PDF 时自动更新页码，用户改稿后在 Word／WPS 里右键“更新域”即可；页码另按 PDF 回填并逐条复核；
  - 表格：排满版心宽，外框 1.5 磅、内线 0.5 磅，五号字、行距固定 14 磅（声明页人员签字表照模板，不改）；
  - 页眉页脚“第X页 共Y页”；
  - 正文仿宋四号，表格五号；
  - 横向页；
  - 表头跨页重复，表题与表同页，标题不落单；
  - 表后的“注：”自动排进表格最后一行；
  - 正文里数值与单位之间的空格不断行。
- **计数**：正文写占位符，生成时按表算出文字，改了表不用再改正文。如 `{{计数:表5.3-1}}` →“表5.3-1共评价18项，其中符合5项、基本符合3项、按补充措施完善后符合10项”；`{{行数:表9.2-1}}`（关键控制点个数）；`{{合计:表8.3-1:金额（万元）}}`。
- **查错**：档位写错或出现“不符合”、计数句与表不符、序号不连续、表／图编号不连续或与所在节不符、引用了不存在的表／图／附件、标准号连接号、括号引号不配对、重复标点、禁用说法（本公司、按可研方案建成、需补充完善、投运前）、11 章章名与 GBZ/T 196—2025 不一致、标题跳号或标题下无内容、4.3 节写了控制要求、出现放射性（电离辐射）内容（第1章写明“另行评价”的除外）、【待填】【待核】未清、项目信息缺项；再加本项目 `检查规则.md` 里的禁用、必备、提示。

正文怎么写（标题、表格、合并单元格、图片、横向页、占位符、检查规则）：看 `references/正文写法格式.md`。

## 4 编写流程

1. **收资料**：按 `references/编制流程与资料清单.md` 第二节向建设单位要，放进项目的 `资料/`；缺项列“待核”清单发给用户。
2. **建项目**：`new`；有同类成稿时也可 `import` 后改（换项目要把事实全部换掉）。用户给了本项目原稿要求改格式或纠错的：先 `import` 原稿成“原稿项目”，逐章盘点节、表（表号、行数）、图和检查表条款，每项定去向，再动笔（`PL-PRE-0042`）。
3. **填 `项目信息.md`**：项目名称、封面名称、报告编号、报告日期、建设单位、评价单位、评价人员、附件清单。
4. **定评价单元和工作场所**：评价单元按工艺系统和辅助系统划分；工作场所按有人作业、巡检的区域或设施划分，操作室、值班室、主控室、装卸车位是所在场所的工作地点，不单列。表1.8-1 定稿前先试排检测布点方案（评价单元｜工作场所｜工种｜工作地点｜接触时间｜因素｜检测方式），走通后再写第4、5章；各章表格照表1.8-1 同名，接触时间只写接触危害的时间、不凑满班长（`PL-PRE-0039`）。
5. **按章写**：先事实章（2 工程分析、3 类比调查），再判定章（4 危害因素、5～8 各项评价），再汇总章（9 关键控制点、10 补充建议、11 结论），最后回头写 1 总论。各章写法看 `references/各章写法/总览_报告骨架与各章要点.md`，口径看 `references/判定规则与口径.md`，易错点看 `references/常见错误与教训.md`。
6. **表格优先**：逐项对照用检查表，清单用一览表（每行注出处），论证和结论写成段落，不塞进单元格（`PL-GEN-0023`）。
7. **build，看校验报告**，改到“错误 0 条”。改写原稿的，每章写完和交稿前各跑一次 `coverage 原稿项目 新项目`，到“错误 0 条”（低于下限的逐节找回，确属应删的写豁免理由）。
8. **跨章连改**：改了某表判定，用占位符写的计数句自动跟着变；第10章的承接、第11章的结论要人工同步。改了共用事实，同步查设计专篇和控评。
9. **交付**：Word、PDF 和交稿说明（本轮改动及依据、自检结果、待建设单位提供或现场核实的事项）。委托书、备案文件、图纸、检测报告等附件另行合订。
10. **积累**：新踩的坑写进 `references/常见错误与教训.md`；本项目的定稿数字写进 `检查规则.md` 的“必备”，已纠正的旧说法写进“禁用”，防止改稿时改回去。

## 7 四档判定（第2、5、6、7章；第8章用前三档）

- **符合**：可研已明确且满足标准。判“符合”的行，建议栏只写落实性要求。
- **基本符合**：可研已明确，种类、数量、参数需细化。
- **按补充措施完善后符合**：可研未涉及或不具体，按本报告补充措施落实后可满足。
- **无设置必要**（第7章叫“无配备必要”）：不存在相应接触或设置条件。

判档前先对可研按关键词计数，确认可研到底提没提（`PL-PRE-0025`）。预评价不判“不符合”（程序会查）。设施与危害机理不对应时不能一律给“基本符合”（`PL-PRE-0034`）。

## 8 口径红线（违反就返工）

- 骨架 11 章不得增删，不得用别的报告（如 10 章结构）替换。
- 预评价**不引用设计专篇和控评**（时序在后），只能写“后续应……”（`PL-GEN-0048`）。
- 已建成项目：已定参数按实际值写，可研值显式标“可研”；不得写“按可研方案建成”（`PL-PRE-0032`）。
- 第6章判定优先；第10章不得反向要求第6章判为不设的设施；应急喷淋洗眼按 GBZ 1—2010 第8.3条两个触发条件（化学性灼伤、经皮吸收急性中毒）判，都不成立就判“无设置必要”（`PL-PRE-0024`）。
- 4.3 只写结论；没用某方法，就不要把表名起成该方法（`PL-GEN-0037`）；不用不适用的国外限值（`PL-GEN-0035`）。
- 第5、7章“小结计数句＝表计数”；档名全文统一（不再用“需补充完善”）；一律写“投产前”。
- 正文不用“本公司”，用“评价组”或无主语句；项目组只写角色，不列姓名；不写未发生的责任主体动作（如“建设单位已对评价组能力进行评估”）。
- 改建、扩建、技改项目：利旧、依托、共用设施和建设单位职业卫生管理情况在评价范围内（GBZ/T 196—2025 第6.1条），不得以“利旧”为由不评。
- 印章、签名、评审意见、第三方事实不臆造；委托书日期按时序预填，在交稿说明里写明是预填、签发前按原件改（`PL-GEN-0050`）。
- **不评价放射性（电离辐射）因素**：职业卫生评价与放射卫生评价分开做，放射性另按 GBZ/T 181—2021 编制。各章不识别、不评价，也不写“无电离辐射源”；项目有放射源或射线装置的，只在 1.4 评价范围写一句“放射性职业病危害因素由建设单位另行委托开展放射性职业病危害评价，不在本报告评价范围内”；第5、7章“防辐射”只指非电离辐射（`PL-PRE-0044`，程序会查）。
- 结论保持“有条件实施”。

细则和出处见 `references/判定规则与口径.md`；全部判例的一句话规则见 `references/常见错误与教训.md`，全文在 `references/判例卡/`。
