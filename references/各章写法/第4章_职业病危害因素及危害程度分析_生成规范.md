## 一、依据：这一章的三条来源

| 层级 | 条款 | 管什么 |
|---|---|---|
| **通则·三分类** | **277 §3.3** | 危害因素＝**生产工艺过程中产生的有害因素**（化学、物理、生物）＋**劳动过程中的有害因素**＋**生产环境中的有害因素**——**三类的识别缺一不可**，这是本章 4.1 分节的根据 |
| **通则·来源与影响人员** | **277 §3.9 ＋ §7.1.2** | 工程分析与前期调查都要"确定主要职业病危害因素及其**来源、发生（散）方式以及影响人员**"——**"来源"要写"怎么产生的"，不是部件名词罗列**（判例 `PL-GEN-0032`）；"**影响人员**"含**接触人员**，以"岗位＋人数"落地 |
| **通则·分析字段** | **277 §7.1.3** | 本章必须回答的字段：工种（岗位）＋工作地点＋**接触方式**＋**接触时间与频度**＋因素**特性**＋**侵入途径**＋**可能引起的职业病及其他健康影响** |
| **通则·服务清单** | **277 第8章 a** | 本章是"接触水平"这一评价内容的底；b—k 由后续各章承接，**不在本章展开** |
| 分节主依据 | **196 §10.2.5** | 本章设三节：10.2.5.1 识别／10.2.5.2 健康效应／10.2.5.3 危害程度 |
| 识别 | **196 §10.2.5.1** | ① 在**原辅材料、生产工艺、生产设备等工程分析**的基础上，**按评价单元**识别危害因素**和来源**；② 明确接触因素的**工种（岗位）及工作地点、作业内容与方式、接触时间与频度**，以及因素的**理化性质、侵入途径**；③ 明确**时空分布**；④ 确定**重点评价的职业病危害因素**；⑤ 还要识别**生产环境、劳动过程**中的危害因素**及其他健康影响因素** |
| 健康效应 | **196 §10.2.5.2** | 描述并分析**理化性质、健康影响、可能导致的职业病、职业接触限值**；**无国内限值的可列国外相关限值或半数致死量等毒理学资料** |
| 危害程度 | **196 §10.2.5.3** | ① 分析强度／浓度**符合国家职业卫生标准**的情况；② 分析**重点评价**因素的暴露情况及**预期接触水平**；③ 对照 **GBZ 2.1／GBZ 2.2** 评价**各类接触作业工种（岗位）**的**符合性**；④ 无检测数据的因素可**定性定量推测**预期接触水平及健康影响 |
| 范围边界 | **196 §6.1 ＋ 矩阵第19节** | **预评价以项目投产后运行期为主要范围**；建设施工与安装调试**如纳入**评价，须另取 GBZ 1—2010、GBZ/T 211—2008、GB 39800 体系、GBZ 188—2025，并确认主管部门要求；**不纳入则须在评价范围处明示** |
| 方法 | **196 §8.1／8.2／8.4／8.5 ＋ 277 附录A.5** | 本章用工程分析法（8.1）＋类比法（8.2，数据来自第3章）＋作业分级（GBZ/T 229 系列）。**§8.4 风险评估法只有在因素能作"接触水平与限值对比"时才用**；没国内限值的因素（单纯窒息性气体等）**不采用该方法**，改按 §10.2.5.3 末句（无检测数据的因素可按定性定量方法推测）作情景分析——**此时方法名、节名、表名、列头一律不得出现"风险评估"**。方法清单在第1章 §1.6 已列，本章**只引用不重复定义，且必须与 §1.6 及表1.6-1 同口径**：不采用的方法不留节、不留行（判例 `PL-GEN-0037`、`PL-PRE-0018`） |
| 数据来源 | **277 §7.1.1** | 引用类比检测数据须**可追溯到检测报告来源**（资料真实性要求）；建设单位资料须盖章或签字（在第1章落实，本章不重复写） |

**优先级与冲突处理**：
- **通则管底限**：三分类识别、来源与发生（散）方式、影响人员、接触方式与时间频度——技术标准没重复写，不等于没有要求；
- **10.2.5 是规范性，与附录冲突时以 10.2.5 为准**；
- **范围边界**：一律按 196 §6.1 与矩阵第 19 节——**预评价以运行期为主要范围**。
  建设期要么纳入并另取标准，要么在评价范围与本章开头各写一句边界说明，**不得一声不响地只写运行期**。
- **一句话**：通则**管识别什么与字段齐不齐**、技术标准**管分节与重点因素**。两本一起取，
  缺一本必留缺口；**通则里"影响人员"这一条不能因为技术标准没写就不做**。
