**优先级与冲突处理**：
- **通则管共性底限，不能因为"技术标准里没写"就不做**（最典型：资料盖章／签字真实性、
  接触方式、影响人员）——**技术标准不重复写通则已有的要求，不等于没有要求**；
- 10.2.4 与附录 C 直接冲突时以 **10.2.4** 为准（规范性）；
- 附录 C／技术标准未覆盖的（如检测方案依据 GBZ 159）回第 8、9 章取；
- **一句话**：通则**管底限**、技术标准**管设不设与写什么**。两本一起取；通则有的、

## 三、四小节结构与判定档位

> 每个小节往下**还要有一层三级标题**——R 项必须挂到三级标题上，不能挂在章的根上。
> 完整的标题骨架、标题 × R 落点表、追加／升级记录见 `第3章_标题结构.md`。
> 本节说的是**每个标题里要答什么**，那份文件说的是**这些标题怎么摆**。

### 3.1 类比项目的选择及可比性分析

| 项 | 内容 |
|---|---|
| 必答问题 | 类比项目是谁？为什么选它？九维度逐项是否相似？差异有哪些？差异对本报告意味着什么？ |
| 依据 | R2、R16、R18 |
| 证据来源 | 拟建项目的可研/立项/备案文件、设计文件、总平面图；类比项目的实际运行资料 |
| 输出形式 | 简短引言（3—5 行）＋ **表3.1-1 九行对照表** ＋ 表下小结一段 |
| 判定档位 | 逐维度判「相同／基本相同／接近／有差异」，**栏内只写相似性与差异本身** |

**写法要点**：

- 引言必须**一句话讲清选它的逻辑**，并**同时交代评价对象是谁**——本项目已建成投运时，
  这一句是专家评审最会挑的地方：现状资料用于类比，**评价对象仍是可研阶段工程方案**，
  不得写成回溯性评价或控制效果评价。
- 引言只写"依据哪条、为什么选、差异在哪张表"，**不要在引言里复述表内的九维度列举**——
  那是重复，且会把表挤出同页（判例 `PL-GEN-0026`）。
- **末栏列头怎么写，栏内就只写什么**。列头为「差异」时：判"相同"的行写「无」；
  **不得把"无台账／工况未记录／不能外推"这类不确定度方法论写进来**（那是 3.4（2）与
  表3.4-1 的职能），也不留"影响判断"句（判例 `PL-GEN-0025`）。
- 影响的去向：**移到表下小结集中说**，不删。C.1 要求给出相似性，差异影响不能凭空消失。
  小结声称某维度"存在差异"时，**该维度在表内必须真有差异内容**，否则自相矛盾。
- **同址类比的正面依据（R18）**：GBZ/T 277—2016 附录 A.2 写的是"与拟评价建设项目相同或相似的
  **企业或场所**"——**"场所"二字直接支持"用本站自身运行现状作类比"**，不必绕弯子论证。
  引言按此写「选用本站运行现状（相同场所）作为类比项目」，比自造说法稳。

### 3.2 类比调查内容

| 项 | 内容 |
|---|---|
| 必答问题 | C.2 的 a—f 六项分别查到了什么？没查到的怎么交代？管理水平（R9）怎么写的？ |
| 依据 | R3—R9、R11 |
| 证据来源 | 类比项目提供的资料、检测报告、体检报告、防护设施与用品台账、管理制度文件 |
| 输出形式 | 首段（资料构成）＋ **表3.2-1 六行一览表** ＋ 体检段 ＋ 管理段 |
| 判定档位 | 逐项「已取得／未取得」；**未取得写缺口与处理，不得反向写成"没有"** |

**首段必须写全的三件事**（判例 `PL-GEN-0027`）：

1. **谁做的**——评价机构自己实施的检测，**不得**写成"建设单位提供的资料"；
2. **编号与日期**——每份资料给全出具机构、编号、采样/检查日、报告/签发日；
3. **资料构成**——有几份、覆盖哪些年份与项目类别。

**体检段（R6、R11）写法**：监护资料构成（在岗／上岗前／离岗时各几人、编号与日期）→
检查依据（原报告载明的旧版本标准 **＋本报告按现行标准的复核**）→ 结论
（是否发现疑似职业病、职业禁忌证、需复查人员，其他异常与目标疾病的关系）→
人员变动情况 → **结果适用的人员与时点在3.4说明；确有资料缺口时，经核实后如实写**。
不得仅因人员变动就断言检查资料不完整，也不得以未发现目标疾病推定全体人员长期无风险。
**先核体检是否覆盖类比岗位**：逐份核受检单位、工种名单和危害因素是否包括类比岗位和主要因素；属其他企业、或不含类比岗位和主要因素的（如集团体检只含炼铁、炼钢岗位，或列的是铸造类因素），不作为类比体检结果，在本段写明不采用的理由（判例 `PL-PRE-0041`）。

**管理段（R9）**：责任制、管理制度与操作规程、管理机构设置、健康检查开展情况、
个体防护用品发放台账——**该段只能写"已有什么"，制度执行记录不完整就写不完整**。

**接触段（R5、R10）**：必须给出**接触人员**的**值**（不是把"接触人员"四个字写进表的调查内容列就算数）——
岗位、人数、工作地点、接触方式、接触时间与频度。**"接触人数"在表里写了、正文没有值，
就是用表行冒充落点**。本项目这类数据在第2章表2.1-3（定员）与第4章表4.1-1（分布），
第3章应给一句把两者连起来。

**防护设施／应急救援设施／个体防护用品段（R8）**：C.2 f 要求调查三者的**配备情况**，
**不能只靠表行**——
- 防护设施：写"配备（设置）情况"；
- 个体防护用品：写"配备情况"——**有发放台账只能支撑"已配备"，不得写成"已使用"**；
- 应急救援设施：**要有独立落点**，不能只在"防护设施"里捎一句。

### 3.3 类比项目职业病危害因素检测

| 项 | 内容 |
|---|---|
| 必答问题 | 近 1—3 年测了什么、什么时候测的、几份资料、彼此什么关系？在本报告的适用性如何？资料缺口要不要补检？ |
| 依据 | R5、R7、R10、R14、R15、R17 |
| 证据来源 | 近 1—3 年检测报告；必要时本机构开展的类比检测（按 GBZ 159 制定检测方案） |
| 输出形式 | 首段（资料年份范围与相互关系）＋ 检测结果表（按因素分表） |
| 判定档位 | **源报告判定 ≠ 本项目预期**，必须分别写 |

**首段必须回答**：

- **年份范围（R14）**——几份资料、各是什么类别（定期检测／评价检测）、测点数量与项目差异；
- **用哪一份作基准**——多份资料时，明写**以哪一份作类比基准**（如最近年份的一份）并说明理由；
- **资料的来源（R17）**——引用时**注明检测报告来源**（出具机构＋报告编号，落在 3.2/3.3 首段与表3.2-1 出处列）；
- **多份资料的关系**——各自测了什么，哪一份作为**类比基准**（要明写）；
- **同一项目有控评、现状评价等多份报告时**（判例 `PL-PRE-0041`）——先核是否同一项目（规模、场所、定员、工艺、设备、防护设施、制度），列出一致项和变化项；再逐点比对检测数据：差值普遍很小（如±3%以内）、不像独立重测的，只作同一量级参考，引用写两次结果的范围，表述中性（“处于同一水平”），不下“照抄”结论；满足附录C.3“近1年～3年”的一份作时效依据，较早的作对照；非夏季测的高温不代表夏季，高温用夏季结果；原报告判定方法的问题（如按接触时间折算区域噪声限值、只测总尘、漏测因素）照旧在3.4指出；评价结论没有变化的不改；
- **未作定量检测的因素要说明评价方法及适用范围**——未规定职业接触限值，既不等于
  资料不足，也不能直接据此判断“并非漏检”。结合危害特点与评价目的，说明采用的工艺分析、
  情景分析或防护措施检查等方法；低温不得称为“浓度检测”。
- **资料不全时的处理**（R14）——影响本次主要结论的资料缺口，应补充调查或有针对性地检测
  后再作判断，不得一律推至设计或控制效果评价；需补检时写明按 GBZ 159 等相关标准制定的
  检测方案与检测依据（R15）。未来工况变化则说明结果的适用条件及复核要求。
  **先写清"有没有可收集的检测资料"这句话本身，再谈补不补**——资料已收集但不适用、
  与根本没有可收集资料，是两种不同的处理。

### 3.4 资料应用及不确定度评估

| 项 | 内容 |
|---|---|
| 必答问题 | 从类比资料能**借鉴**什么经验？现在还**存在**什么问题？资料适用于哪些工况、人员及调查范围，对具体结论有什么影响，如何处理？ |
| 依据 | R12、R13、C.4 |
| 证据来源 | 3.1—3.3 全部 |
| 输出形式 | 两段：**（1）可借鉴的经验 /（2）存在的主要问题及不确定度**（表3.4-1 承载问题明细）＋ **表3.4-1** ＋ 表下注 |
| 判定档位 | 结论不超出资料支持范围；表内写必要的资料处理或复核方式，具体**措施建议归第10章** |

> **格式提示**：两段若升为三级标题（`3.4.1 可借鉴的经验`／`3.4.2 存在的主要问题及不确定度`），
> **必须删掉正文里的「（1）（2）」编号**，否则出现「3.4.1（1）」的双重编号。
> 未升标题时保留「（1）（2）」。见 `第3章_标题结构.md` 一·约束 3。
> （2026-10-03 由三段并为两段：不确定度独立成段会把同一批事实在判定段、正文、表里说三遍——
> 判例 `PL-GEN-0030`。）

**两段的边界必须守住**：

- **（1）可借鉴的经验**——写类比项目**已经做到**的什么，可作为本项目设计的参照（依据 C.4）；
  噪声合格只支持相应工况下的噪声判断，体检未发现目标疾病只支持对应人员与时点的结果，
  两者不能合并推定全部主要危害已受控。
- **（2）存在的主要问题及不确定度**——**正文只留一至两句引出表3.4-1**，问题明细全部进表：
  每行讲清“资料适用条件是什么、影响哪项结论、如何处理”，重复来源可合并，**不为凑项而
  推定资料有缺陷**。本项目采用三列表式，标准没有规定固定列数、评分等级或合成公式。
  资料不确定度覆盖调查、检测和健康监护等资料的使用范围，不等同于实验室测量不确定度。
  表内只保留必要处理方式与相关章节指针，**不得展开成措施清单**。
- **表下注**说明资料按相应工况、人员及调查范围使用；影响本次主要结论的资料缺口，
  应补充调查或有针对性地检测后再作判断。不得要求所有不确定度一律在后续“逐项闭合”，
  因为正常的工况或人员变化需要明确适用条件，并非均属待补资料。
- **同一批事实只说一次**：3.3 判定段只写判定＋「适用边界见表3.4-1」一句指针；
  3.4 正文不再复述表内任何一条（判例 `PL-GEN-0030`）。

## 五、禁止事项（写这一章时逐条对照）

1. **不得照抄标准条文**。10.2.4 与附录 C 是**问题清单**，不是要抄进报告的段落；
   报告里出现"本报告设置本章节"这类元描述就是抄条文。
2. **不得把拟采取措施写成已执行事实**（预评价通例）：可研只说"投产前建立制度"，
   就只能写"可研仅要求投产前建立，尚无执行记录"，不能写成"已建立"。
3. **不得与邻章职责串味**：措施建议归第10章；因素识别与危害程度归第4章；
   防护设施评价归第5章。本章只做"从类比资料能推出什么 + 推不出什么"。
4. **不得凭空断言资料"没有"**。关于资料本身的断言（谁做的、几年、含不含某类检查、
   谁提供的）全部是**可被附件直接证伪的事实**，写前逐份打开核对（判例 `PL-GEN-0027`）。
   核对不到结论时写"资料已取得、结论未见"，**绝不可反向写成"未含／没有"**。
5. **不得把同一个事实在第1章与第3章写成两种说法**（出处列与 §1.2 依据清单必须同步，
   判例 `PL-PRE-0031`）。
6. **不得由“未设接触限值”直接推定漏检、资料不足或“并非漏检”**。资料是否满足评价需要，
   应按危害特点、岗位接触、工况及评价方法判断；确需补检时按R14执行，不能全部推至后续阶段。
7. **不得让"差异"栏承载不确定度**（判例 `PL-GEN-0025`）——见 3.1 写法要点。
8. **不得只对技术标准、不对通则**（判例 `PL-GEN-0029`）。
   **通则（GBZ/T 277—2016）与技术标准不重复写同一件事——技术标准里"没写"不等于"没有要求"。**
   本规范 R17／R18 全部来自通则；只读 GBZ/T 196 一条都看不到。
   **写之前先把两本摊开（通则／技术标准），三类来源一次取齐再动笔。**
