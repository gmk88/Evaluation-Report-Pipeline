# 第3章 标题结构（骨架）

> **性质：骨架，不是内容。** 与 `第3章_类比企业（项目）调查与分析_生成规范.md` 配套：
> 规范回答「这一章要答哪些问题」（R1—R18），本文件回答「**这些要求各挂在哪个标题下**」。
>
> 两者缺一，规范就落不到纸上：**只有 R 清单、没有标题落点，写的时候仍然不知道某一条该
> 写在谁下面**；反过来只有标题、没有 R，标题就是空壳。
>
> **适用阶段**：预评价且采用类比法（同规范）。设计专篇 / 控评 / 现状评价**不设本章**，
> 不得把本结构照搬过去。
>
> 建立日期：2026-10-03。

```
│   ├─ 3.1.1 类比项目的选择

│
├─ 3.2 类比调查内容
│   ├─ 3.2.1 调查资料构成及来源
│   ├─ 3.2.2 类比调查内容及资料取得情况

│
└─ 3.4 类比调查与检测资料应用及不确定度评估
    ├─ 3.4.1 可借鉴的经验

```

**四条设计约束**（照规范与既有基线，不是美观取舍）：

1. **四节编号与节名不动**——`3.1`—`3.4` 是原稿起草时即有的结构，已进目录、已进生成器落点，
   本节只往下长一级，不改上面两级。
2. **三级标题数由「可核对的落点」定**，不由篇幅定——每个三级标题至少承载 1 个 R 项。
   R 项无处可挂时，先加标题再补内容；**不允许把 R 项挂在章的根上**。
3. **3.4 的「（1）（2）」升级为真标题**——升级后**必须删掉原「（1）（2）」编号**，
   否则出现「3.4.1（1）」的双重编号。（2026-10-03：3.4 已由三段并为两段——
   问题明细并入表3.4-1，不确定度不再独立成段，判例 `PL-GEN-0030`。）
4. **表格挂在内容所在的三级标题下，不单设「表格」节**——表随文走，表号体例不变。

## 三、为什么 3.2 只拆四个三级标题（而不是 a—f 六项一一对应）

C.2 是 a—f 六项，直观做法是拆六个三级标题。本结构**不这么做**，理由有三条：

1. **a—f 六项已在表3.2-1 里一行一项**，表已经把六项对齐了；标题再拆一遍是**同一层信息做两遍**。
2. **3.2 的实际内容撑不住六个标题**：本节内容为「首段（资料构成）＋ 汇总表 ＋ 体检段 ＋ 管理段」，
   六拆后有四节会退化成**只有标题、没有正文的空壳**——空壳标题在评审眼里比不拆更差。
3. **a—f 里的 e 项（检测报告）本来就是 3.3 的整节内容**，在 3.2 下再设一节会造成
   「同一份资料在 3.2、3.3 各有一节」的重复。

**代价与兜底**：R3／R4／R5／R8 四项**共用一个三级标题（3.2.2）**。
兜底靠**表3.2-1 六行 ＋ 表下逐项正文段**：表行负责"取得没取得"，正文段负责"具体是什么"。
**只要 3.2.2 的正文段按 a—f 顺序逐项写，对应关系一样清楚**——这是本结构唯一需要靠行文纪律
维护的地方，写的时候按 a—f 打头标号（a）…（f）即可。

3.2.2 把 R5（接触情况）、R8（三类防护与用品）压在同一节，是**现状内容撑不住时才合并**的妥协。

应追加三个三级标题、恢复与 C.2 的对齐关系：

| 追加标题 | 承接 | 触发条件 |
|---|---|---|
| **3.2.x 生产工艺及生产设备** | R4（C.2 b）拆出 | 3.2.2 中 b 项正文超过 1 段 |
