# 先读：这个目录怎么用

本目录的第3、4、5、7章文件原样复制自马沟项目记忆包 `05_章节生成规范/`（2026-10-09 快照），是“逐条必答问题＋标题落点＋自检”规范；`总览_报告骨架与各章要点.md` 是 11 章的总要点（新写）。用之前注意：

1. **先看总览**：`总览_报告骨架与各章要点.md` 覆盖全部 11 章，写每章前先看对应一节。
2. **第3章、第4章**：规范、标题结构可直接用；`范例_第3章正文_马沟.md` 故意带马沟事实，只作“写足了什么样”的标尺，**换项目不要复制**。
3. **第5章三件套（规范／标题结构／生成提示词）已过时**：马沟最终版第5章已整章重写为四节＋四档（符合／基本符合／按补充措施完善后符合／无设置必要）；三件套里的“两节”和“合理／基本合理／不合理／不适用”是旧口径，只参考它“问题清单”的思路。现行口径以总览、`../马沟项目记忆原文/02_分册_MEM/08-第5第7章口径.md` 和 `../../examples/马沟/正文/05_职业病防护设施分析与评价.md` 为准。
4. **第7章规范是 v0**（2026-10-05 起草，部分条号待补），结构与最终版一致，可用；引用未取得全文的标准时只写名称。
5. **第8—11章没有单独规范**：看总览和 `../马沟项目记忆原文/02_分册_MEM/10-第8至11章口径.md`。
6. 文中提到的 `build_review.py`、`chapter5_data.py`、`finalize_review.py`、`_work/…`、`知识库/`、`.workbuddy/memory/` 是马沟当时本机工作区的生成器和路径，skill 里没有，也不再需要：现在正文直接写在项目文件夹的 `正文/*.md` 里，用 `scripts/report.py build` 生成。判例在 `../判例卡/`，马沟项目口径在 `../马沟项目记忆原文/`（文中 `MEM/08` 即 `02_分册_MEM/08-…md`）。
