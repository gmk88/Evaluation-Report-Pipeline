# 随 skill 带的第三方库

- `fontTools/`：fontTools 4.68.0（MIT 许可，许可证在 `fonttools-4.68.0.dist-info/licenses/`），只放纯 Python 部分，去掉了编译过的 `.so`（各模块都有同名 `.py`，功能相同）。
- 用途：`scripts/pe/embed_fonts.py` 把仿宋、宋体、Times New Roman 裁成报告用到的字，嵌进 WPS 命令行导出用的渲染副本；`scripts/pe/render.py` 没有仿宋时生成替身字体。
- 本机已装 fontTools 的，优先用装好的；没装的才用这里的（`scripts/report.py` 把本目录加在搜索路径最后）。
- 来源：2026-10-30 晋钢烧结项目 `工作区/工具/WPS导出/_deps/`，366 个文件与其 RECORD 记录的哈希逐个一致。
